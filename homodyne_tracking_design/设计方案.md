| 档位 | fn | ζ | B_loop(离散实测) | f_3dB | 带内纹波 | 3 MHz 处 \|H_L\| | 弱光线性上限 @B=40 MHz | 实测局部 SNR 增益 @CNR 3 dB |
|---|---|---|---|---|---|---|---|---|
| SLOW | 110 kHz | 2.65 | 0.956 MHz | 0.61 MHz | 2.85 % | −14.3 dB | +13.2 dB | **+34.7 dB** |
| MEDIUM | 530 kHz | 2.65 | 4.74 MHz | 3.02 MHz | 2.87 % | −3.0 dB | +6.3 dB | **+17.3 dB** |

核心改动:**ζ 从 1.2 提到 2.65(等纹波设计)**,fn 基本不动。ζ=1.2 的闭环有 +11.4 % 峰化、档边缘 −10.9 %,根本达不到 3 % 幅值预算;ζ=2.65 时峰化恰好压到 +2.9 %,平坦区(误差≤3 %)延伸到 1.94·fn,整个使用频带 ±3 % 免校正。

## 1. 三档参数推导

### 1.1 ζ 的推导(等纹波条件)

连续近似闭环幅频(x = f/fn):

```
|H_L(x)|² = (1 + 4ζ²x²) / ((1−x²)² + 4ζ²x²)
```

PI 零点造成带内峰化,峰值位置 u* = x*² = (−1+√(1+8ζ²))/(4ζ²)。
幅值误差 ≤3 % 需要同时满足:

1. 峰化 ≤ +3 %:解 |H_L(x*)| = 1.03 得 **ζ ≥ 2.575**;
2. 档边缘 ≥ −3 %:解 |H_L| = 0.97 得 **x_edge ≤ 1.944**(ζ=2.65)。

取 ζ = 2.65(不是 2.575 临界值):250 MS/s 的精确离散响应在 FAST 档峰化比连续值略高,2.65 保证离散纹波 2.85/2.87/2.92 % 均 <3 %。

### 1.2 fn 的推导

`fn = f_max / 1.875`(在 1.944 交点内留余量):

- SLOW(f_max=200 kHz): fn = 110 kHz
- MEDIUM(f_max=1 MHz): fn = 530 kHz
- FAST(f_max=3 MHz): fn = 1.60 MHz

环路增益(θ = 2π·fn/fs, Kp = 2ζθ, Ki = θ²):

| 档位 | Kp | Ki |
|---|---|---|
| SLOW | 1.465e-2 | 7.643e-6 |
| MEDIUM | 7.060e-2 | 1.774e-4 |
| FAST | 2.131e-1 | 1.617e-3 |

### 1.3 门控参数推导

门控是**掉落检测器**,不是 FM 门限检测器(SnrOn 若设 3.0,CNR 3 dB 的弱光永远进不了 LOCK):

- **SnrOn = 1.0 / SnrOff = 0.3**(全档相同):最弱规格光 CNR 3 dB → snr 估计≈2.0 > SnrOn,可靠进锁;掉落 10 dB 即触发 SnrOff,迟滞比 3.3 倍防抖。
- **TauP**(功率平滑):估计相对标准差 ≈ 1/√(2·B_frontend·TauP)。要求 σ_rel ≲ 15 %(B=40 MHz 时 TauP ≥ 0.6 µs)且检测延迟 ≪ 最短散斑衰落(~10 µs)。按档位动态取:SLOW 4 µs(σ_rel 6 %)、MEDIUM 2 µs(8 %)、FAST 1 µs(11 %)。
- **TauF**(粗频率 IIR):σ_f ≈ fs/(2π)·1/√(2·B_frontend·TauF),需 ≪ 捕获范围(~20·fn)。SLOW 8 µs(σ_f≈0.6 MHz < 2.2 MHz)、MEDIUM 2 µs、FAST 1 µs;AcquireTime = 4·TauF。
- rel_on/rel_off = 0.20/0.08,tauRef = 200 µs(相对衰落判据,防止死通道分权重)。

## 2. 每档预期指标

公式:B_loop = π·fn·(1+4ζ²)/(4ζ) = 8.62·fn(连续);f_3dB = 5.49·fn;a_design = πλfn²;线性上限 = 10·log10((B_frontend/2)/B_loop);σ_φ² = B_loop/(CNR_lin·B_frontend)。

| 指标 | SLOW | MEDIUM | FAST |
|---|---|---|---|
| B_loop 连续 / 离散积分 | 0.948 / 0.956 MHz | 4.57 / 4.74 MHz | 13.8 / 15.5 MHz |
| f_3dB(离散) | 0.61 MHz | 3.02 MHz | 9.96 MHz |
| a_design (e_ss=1 rad) | 5.89e4 m/s² | 1.37e6 m/s² | 1.25e7 m/s² |
| 3 MHz 处 \|H_L\| | −14.3 dB(超出使用带) | −3.0 dB(超出使用带) | −0.11 dB,误差 1.3 % |
| 线性上限 @B=40 M | +13.2 dB | +6.3 dB | +1.1 dB |
| 线性上限 @B=20 M | +10.2 dB | +3.2 dB | −1.9 dB |
| 锁内 σ_φ @CNR 3 dB, B=40 M | 0.109 rad | 0.239 rad | 0.416 rad(边缘) |
| 实测局部 SNR 增益 @3 dB(32 种子中位数) | +34.7 dB | +17.3 dB | +2.0 dB |
| 实测宽带速度噪声压缩 @3 dB | 25.6×(+28 dB) | 5.5×(+15 dB) | 2.0×(+6 dB) |

两点必须说清:

1. **实测增益远超"线性上限"不是矛盾**:10·log10((B/2)/B_loop) 是已锁定线性区的相位底噪改善;CNR 3 dB 时 OFF 鉴频器深在 FM 门限之下(OFF 相位噪声方差 0.25 rad²),click 噪声抬高底噪,PLL 环内 CNR = 3 dB + 上限值,越过门限后 click 消失——门限扩展的非线性收益叠加在线性收益之上,SLOW 实测 +35 dB。
2. **FAST 档的诚实边界**:B_loop=15.5 MHz 已接近 B_frontend/2=20 MHz,线性上限只有 +1.1 dB;σ_φ=0.42 rad @CNR 3 dB 处于周跳边缘,弱光下 FAST 建议 CNR ≥ 6 dB。这是"3 MHz 平坦 + 20 MHz 单边前端"的物理极限,不是参数没调好。**FAST 档要求 B_frontend = 40 MHz**(20 MHz 时 B_loop > B_frontend/2,相对 OFF 无线性收益);SLOW/MEDIUM 用 20 或 40 MHz 均可。

## 3. 档位切换规则(频段优先 + 加速度守卫)

**主判据按目标频段,加速度只做守卫**——零差测超声的典型场景是"高频小振幅",加速度几乎从不先违约(20 mm/s @3 MHz 才 3.8e5 m/s²,离 FAST 的 a_design 还有 33 倍);低频大振幅冲击才由加速度规则接管:

1. **频段规则**:选能覆盖目标频率的最窄档(f ≤ 200 kHz → SLOW;≤ 1 MHz → MEDIUM;≤ 3 MHz → FAST)。最窄档 = 最低 B_loop = 最高弱光灵敏度。
2. **加速度守卫**:估算 a_pk = 2πf·v̂_pk,要求 a_pk ≤ 0.3·a_design(即 e_ss ≤ 0.3 rad);超过则逐级升档。例:150 kHz/500 mm/s → a_pk=4.7e5 > 0.3×5.89e4,SLOW、MEDIUM 都不够,升到 FAST。
3. **运行时自动回退**:非 LOCK 占比 > 1 % 或 near-π 事件率 > 10 /s → 升一档;长时间干净且下档同时满足规则 1、2 → 允许降档。

## 4. 与暂定 0.2/1/3 MHz 方案(fn=106k/529k/1589k, ζ=1.2)对比

| 项 | 暂定方案 | 本方案 | 说明 |
|---|---|---|---|
| 档边缘幅值误差 | −10.9 %(设计成 −1 dB) | −1.3 ~ −2.2 % | 暂定方案直接打穿 3 % 预算 |
| 带内峰化 | **+11.4 ~ +11.6 %**(在 0.66·fn 处) | +2.9 % | 暂定方案连"带内"都不平:FAST 档在 1.05 MHz 处 +11.6 %,而 1–3 MHz 恰是 FAST 的使用区 |
| 3 MHz 实测幅值(仿真) | 0.913(−8.7 %) | 0.987(−1.3 %) | 时域 burst + 精确速度参考实测 |
| FAST B_loop / 线性上限 | 7.03 MHz / +4.5 dB | 15.5 MHz / +1.1 dB | 平坦度的代价 ≈ 2.9 dB 上限;换来免校正 ±3 % |
| 门控参数 | 全档共用 TauP=TauF=1 µs | 按档位缩放(4/2/1 µs 等) | SLOW 档功率估计方差降 4 倍,粗频率精度提升 |
| 切换规则 | 无明确规则 | 频段优先 + 加速度守卫 + 自动回退 | 可直接写状态机 |

改进点总结:**fn 几乎没动(106k→110k, 529k→530k, 1589k→1600k),真正的修复是 ζ**。暂定方案的问题不在档位划分,而在 ζ=1.2 的响应形状——"档边缘 −1 dB"听起来合理,但 −1 dB 就是 10.9 % 误差,且中途还有 +11 % 峰化。等纹波 ζ=2.65 用约 2.9 dB 的灵敏度上限换来全带 ±3 %,对 SLOW/MEDIUM(上限仍有 13/6 dB,实测 35/17 dB)完全值得;FAST 本来就贴着物理极限,损失的 2 dB 换来规格达标。
