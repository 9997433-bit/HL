# （gen-char-play-rich.mjs 的 narrationKey）。凑条数糊弄不过去。

# templateFallback = true），这里的每一条都是 templateFallback = false。
#
# 每行五个字段，用 | 分隔：
#
#   汉字 | 主题 | 模板 | 旁白（念给孩子听的一句） | 道具
#
# - 主题（theme）取值见 gen-char-play-rich.mjs 里的 THEMES：
#   number nature weather animal body family school food color shape
#   time place action object word feeling
# - 模板（template）取值见同一个文件里的 TEMPLATE_CATALOG，每个模板都标了
#   交互类型（tap / drag / swipe / sequence），舞台没实现某个模板时可以按
#   交互类型退化，但不会退成空白卡。
# - 旁白写给 4–6 岁的孩子：一句话、不超过 24 个字、说清楚「现在要干什么」。
# - 道具（props）写成 key=value，用 ; 分隔；value 里的 , 表示列表，
#   : 表示成对（pairs / buckets / 分桶版的 items）。常用键：
#     hero    主角 emoji
#     items   可交互的一堆 emoji（分桶模板里写成 emoji:桶名）
#     decoys  干扰项 emoji
#     tool    手里的工具 emoji（伞、手电、纸巾…）
#     stages  变形 / 生长的分镜，按顺序播
#     parts   要拖到一起的零件（可以是 emoji，也可以是部件字）
#     pairs   要连线的成对项，写成 左:右
#     buckets 分类筐，写成 筐名:emoji
#     dir     滑动方向 up / down / left / right
#     sound   发声玩法要念的拟声词
#     color   涂色玩法的颜色
#     word    组词玩法要拼出来的词
#     goal    要完成几次有效交互（默认 3），reduce-motion / 跳过时不影响通关
#
# 生成物：src/data/char-play-rich.js（node scripts/gen-char-play-rich.mjs）
