# MathQuest · 数学星球大冒险

开源儿童数学 Web 应用(3-12 岁),对标并超越洪恩数学。太空冒险主题,纯前端、
进度存在本机 localStorage,不需要账号也不上传任何数据。

**版本状态(Round 3 · SOTA 终验进行中)**:Round 2 实测基线为 QuizShell 统一答题壳、
118 个应用题母题、4×4/6×6/9×9 数独、14 类错因统计、Tone.js 移除后主包 gzip ~80KB、
离线 Service Worker。Round 3 攻坚项:家长面板(防沉迷/报表/导出)、axe serious 清零、
设计令牌迁移、题库 ≥300、Lighthouse ≥ 90 终验。
终验实测见 `.agent_workspace/GLOBAL-SUMMARY-REPORT.md`。

## 快速开始

```bash
npm install
npm run dev            # http://localhost:5174
npm run build          # 产物在 dist/,可直接静态托管
npm run preview        # 本地预览构建产物
```

## 离线使用

生产构建会生成带版本号的 Service Worker 预缓存，覆盖 `index.html`、全部 Vite 资源和所有懒加载玩法。部署到 HTTPS 静态站点（本机可用 `localhost`）并至少联网打开一次；Service Worker 安装完成后即可断网刷新或重新打开。

Service Worker 不支持 `file://`，不能通过直接双击 `dist/index.html` 安装离线缓存。可在仓库根目录运行 `npm run build && npm run test:offline`，验证关闭 HTTP 服务后仍能启动数独路由。

## 质量校验

```bash
npm run check:content  # 不开浏览器:题库与生成器跑几千次,查负数答案/重复选项/数独多解
npm run smoke          # 无头 Chrome:12 条路由 + 20 项交互,查控制台报错与渲染事故
npm test               # 上面两项 + 一次完整构建
```

`check:content` 校验的是内容正确性:母题总数不得少于 100 个、场景不得少于 30 种,
每个应用题母题各生成 2000 道,确认答案是非负整数、
题干里没有 `NaN` 或没替换掉的占位符;语义模板 × 场景皮肤的笛卡尔积要铺满,
整个题库在 `reseed(seed)` 之后必须逐字复现、换 seed 才换题;数独 4×4 / 6×6 / 9×9 三档连出上百局,确认每局都是
唯一解且题面本身无冲突;选项生成器抽 5000 次,确认四个选项互不相同且必定包含正确答案;
穷举各玩法的技能点映射,确认产出的 id 全在技能图谱里、且每个应用题技能点都有母题能练到;
音效谱面的音名逐个解析,确认没有拼错导致某个音静默消失。另外校验题目的可复现性:
同一个 seed 的两条随机流逐位一致,比大小题按 seed 重建后完全相同,每日冒险连算 400 天,
每一道都能凭题目 id 里的 seed 原样重建,而相邻两天不会出同一套题。

`smoke` 校验的是真实浏览器里的行为:每条路由都要能挂载、不许出现 `NaN` / `undefined`
泄漏到界面上,每个玩法连答 6 题,数独一路解到完成态,成就墙的改名/导出/清空要真的生效,
答完题刷新页面进度还得在,把年龄档改成 L1 与 L5 后六个玩法的起步难度都要跟着变。装货题用真实鼠标事件驱动(货物走的是 pointer 事件,
合成 `click` 测不出真实行为),另有一条用例专门确认键盘也能装货。

## 七大模块(7 颗星球)

| 星球 | 模块 | 路由 | 玩法 |
|------|------|------|------|
| 数字星球 | 数与量启蒙 | `/number-sense` | 拖拽装货点数(1-20)、数量识别、数序填空、比大小 |
| 比大小擂台 | 数与量专项 | `/compare` | 只出 `>` `<` `=`,两边同时给数字与实物,四题里有一道「一样多」 |
| 计算星球 | 加减乘除 | `/arithmetic` | 10 以内 / 100 以内切换,选择与数字键盘两种作答方式 |
| 图形星球 | 几何空间 | `/geometry` | 平面/立体/混合三档,认名字、找同类、数边数、找生活中的形状 |
| 逻辑星球 | 逻辑推理 | `/logic` | 图形与数字找规律、旋转规律、分类推理 |
| 数独星球 | 数独专项 | `/sudoku` | 4×4/6×6/9×9 三档唯一解数独,冲突高亮、提示、数字/图案两种皮肤 |
| 故事星球 | 应用题 | `/word-problems` | 118 个生活场景母题(55 个一步 / 40 个两步 / 23 个进阶),分级提示与算式讲解 |
| 星图中心 | 进度系统 | `/progress` | 成就墙、各星球掌握度、最近练习曲线、学习报告导出 |

### 年龄档(L1–L5)

家长中心里选一次年龄档,六个玩法进来时的默认难度就都跟着走。映射表只有一份,
在 `src/data/age-band.js` 里:

| 档位 | 数量星云 | 算术恒星 | 形状卫星 | 规律环带 | 数独空间站 | 生活行星 |
|------|----------|----------|----------|----------|------------|----------|
| L1 3–4 岁 | 数到 8 | 10 以内加法 | 平面图形 | 图案循环 | 4×4 简单 | 一步应用题 |
| L2 4–6 岁 | 数到 20 | 10 以内加减 | 平面图形 | 图案与简单数列 | 4×4 简单 | 一步应用题 |
| L3 6–8 岁 | 数到 20 · 跳着数 | 20 以内进退位 | 平面 + 立体 | 数列与循环 | 6×6 简单 | 全部题型 |
| L4 8–10 岁 | 数到 40 · 跳着数 | 100 以内加减 | 立体图形 | 倍数与复合规律 | 6×6 普通 | 两步应用题 |
| L5 10–12 岁 | 数到 60 · 大跨步 | 100 以内加减 | 平面 + 立体 | 复合与交替规律 | 9×9 简单 | 进阶多步题 |

档位决定的不只是数值上限:数量星云连题型配比一起换(低龄多装货多点数、
高龄多数序多比大小),规律环带按档位开放题型(翻倍、差值递增、交替加减只在高档出现),
形状卫星按档位决定平面/立体范围与题型。孩子在玩法页里仍然可以自己切档,
年龄档只决定「从哪儿起步」;家长改档后,孩子当前停留的那一页会立刻按新档位重开一轮。

### 今日冒险(`/daily`)

首页 hero 的主按钮。每天固定 5 题,依次是点数 → 加法 → 比大小 → 减法 → 数序,
第 n 题的种子固定为 `YYYY-MM-DD#n`,所以同一天刷新页面、甚至换一台设备,
看到的都是同一套题——做到一半被打断也能接着做完。完成情况(含连续打卡天数)
记在 `progress.dailyQuest` 上,同一天重复完成不会重复发奖。

### 逻辑小游戏(`/memory-pairs`、`/maze`)

两个 Canvas 玩法,归在逻辑星球下,难度跟着年龄档 L1–L5 走,页面里也能自己切档。

- **配对记忆** 翻两张牌配对。低龄档配两张一样的牌,高龄档配同一类的两张不同牌
  (🍎 和 🍇 都是水果),后者练的是技能点 `classify`。画布只负责画,交互与无障碍
  走盖在画布上的一层透明按钮:每张牌一个 `button` + `aria-label`,键盘也能整局玩完。
- **逻辑迷宫** 随机化 DFS 生成的完美迷宫,一局三关。按 ①②③ 的顺序收齐能量块,
  空间站的舱门才会打开——「先做哪一步」这层条件对应技能点 `maze-condition`。
  画布可聚焦并接方向键,另配一组方向按钮供触屏与读屏用户使用;提示按 BFS 最短路
  给出下一步方向。

两者的生成与求解都收在 `src/core/engine/`(`memory-pairs.js` / `maze.js`)里,是不依赖
框架的纯函数,`check:content` 每次跑 1000 副牌与 200 座迷宫做回归:牌堆必须两两成对、
同类档确为同类,迷宫必须每格可达,而且只跟着提示走就能按最短路线通关。

动效降级:`prefers-reduced-motion`(或家长关掉动效)时两个玩法都不跑 rAF 补间,
翻牌与飞船直接落位,能量块的光晕也一并关掉。这条降级由 `npm run smoke` 里的
两项探针把关——正常档前后两张画布截图必须不同,降级档必须完全一致。

## 架构

- `src/core/engine/` — 玩法引擎层(纯函数、可在 Node 里直接跑):`sudoku`、`adaptive`
  (自适应出题)、`maze`(迷宫生成/求解/关卡编排)、`memory-pairs`(牌堆编排);
- `src/utils/` — 纯 JS 引擎层(无框架依赖,可在 Node 里直接单测):`sudoku`(4×4/6×6/9×9
  生成与唯一解校验)、`mastery`(掌握度模型)、`sound`(Web Audio 合成音效)、
  `random`(mulberry32 随机流与选项生成);
- `src/data/` — 课程技能图谱(L1-L5)、技能点映射、年龄档 → 各玩法默认难度、星球元数据、
  成就定义、应用题母题库(手写母题 + 语义模板 × 场景皮肤的笛卡尔积)、比大小与每日冒险题库;
- `src/stores/` — Pinia:`progress`(掌握度/星星/经验等级/连击/成就/打卡/错因统计,
  localStorage 持久化)、`settings`(音效/护眼/年龄档);
- `src/composables/` — `useFeedback`(GSAP 答对答错反馈、星星飞入、粒子迸发)、
  `useAgeBand`(读当前年龄档的默认难度,家长改档后重开一轮);
- `src/modules/` — 首页地图与七大模块视图,路由指向的视图全在这里;
- `src/components/` — 星空画布、顶栏、成就吐司等共享组件。

每件事只有一个入口,新增玩法时沿用即可:进度读写走 `stores/progress`,声音走
`utils/sound`,「这道题算哪个技能点」走 `data/skill-mapping`,「这个年龄档从多难开始」走
`data/age-band`。技能 id 写错不会静默,`recordAnswer` 会拒绝记录并在开发期打警告,
`check:content` 也会拦下;年龄档里写了某个玩法不认识的档位,同样会被 `check:content` 拦下。

出题不用 `Math.random`:随机数一律取自 `createRng(seed)` 建的 mulberry32 流,
题目 id 是 `` `${templateId}:${seed}` ``,凭 id 就能把同一道题一字不差地重建出来——
每日冒险靠它保证「同一天同一套题」,回归测试靠它做可复现断言。

音效是用 Web Audio 的振荡器 + 增益包络现场合成的,不打包任何音频文件,也没有音频库依赖。

完整设计见 `/.agent_workspace/math-architecture.md`。
