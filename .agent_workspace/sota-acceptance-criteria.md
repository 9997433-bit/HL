# SOTA 验收标准 — 识字 App 与 数学 App

> 版本：Round 1 v1.0（2026-08-26）
> 配套：`.agent_workspace/ui-ux-design-spec.md`（设计规范）、`.agent_workspace/test-baseline.md`（构建基线）
> 目标：每一条都可被脚本或 10 分钟内的手动步骤验证，最终两 App 全量达标即为 SOTA。

## 0. 验收总则

- **优先级**：P0 = 不达标不得出包；P1 = Round 3 结束前必须达标；P2 = 加分项（超越洪恩的差异化）。
- **环境**：以 `npm run build:all` 产物 zip 解压后经静态服务器（如 `npx serve`）访问为准；性能项在 Chrome DevTools「4× CPU 节流 + Fast 3G→离线切换」下测。
- **轮次门槛**：Round 1 通过全部构建级 P0；Round 2 通过全部功能 P0 + 性能 P0；Round 3 全部 P0/P1 清零。
- **工具**：Lighthouse（Performance/Accessibility/Best-Practices）、axe DevTools、Chrome Performance 面板、`scripts/verify-resources.sh`、手动走查脚本（见 §5）。

## 1. 识字 App（literacy-app）验收清单

### 1.1 功能（P0 除非另注）

| # | 验收项 | 通过标准 |
|---|---|---|
| L-F1 | 字库规模 | Round 2 ≥ 100 字、Round 3 ≥ 200 字（分级：启蒙/基础/进阶），每字含拼音、儿童释义、例词、笔顺数据 |
| L-F2 | 单字学习闭环 | 每字完成「认（大字卡+读音）→ 写（HanziWriter 描红）→ 测（听音选字/看字选音）」三环节，环节间自动衔接 |
| L-F3 | 笔顺书写 | 笔顺演示动画可重播；描红逐笔判定，错 3 次自动示范该笔；完成后整字回放 |
| L-F4 | 听音识字 | 语音播报 + 2×2 选项；答错温和提示并允许重试，不进入惩罚流 |
| L-F5 | 复习系统 | 基于间隔重复（学过的字按遗忘曲线进入复习队列）；复习队列在首页可见 |
| L-F6 | 成语/绘本模块（P1） | ≥ 20 条成语（拼音+浅释+互动）或 ≥ 5 本分级绘本（逐句朗读高亮） |
| L-F7 | 奖励系统 | 星星/徽章即时发放，进度页可回看；庆祝动画可跳过 |
| L-F8 | 家长面板 | 家长门验证进入；可查看学习字数/时长/正确率，可调主题、字号档、音量三总线、动效开关、单次使用时长提醒 |
| L-F9 | 进度持久化 | localStorage/IndexedDB 存储；刷新/断网/重开浏览器后进度无损；可导出/导入 JSON（P1） |
| L-F10 | 防沉迷 | 达到家长设定时长（默认 20min）弹出角色化休息提醒 |

### 1.2 性能（P0）

| # | 指标 | 阈值（4× CPU 节流，本地静态服务） |
|---|---|---|
| L-P1 | Lighthouse Performance | ≥ 95 |
| L-P2 | FCP / LCP / TTI | < 1.0s / < 1.5s / < 2.0s |
| L-P3 | CLS / TBT | < 0.05 / < 150ms |
| L-P4 | 首屏 JS 体积 | < 250KB gzip（笔顺数据按字懒加载，单字 < 30KB） |
| L-P5 | 动画帧率 | 学习流程连续操作 60s，平均 ≥ 55fps，无 > 50ms long task |
| L-P6 | 音效延迟 | 点击到发声 < 100ms（预解码，播放路径零网络请求） |
| L-P7 | 内存 | 连续使用 30min，JS heap 增长 < 20%（无泄漏） |

### 1.3 无障碍（P0 除非另注）

| # | 验收项 | 通过标准 |
|---|---|---|
| L-A1 | Lighthouse Accessibility | ≥ 95 且 axe 无 critical/serious |
| L-A2 | 触控目标 | 儿童界面全部 ≥ 56×56 CSS px，相邻间距 ≥ 8px |
| L-A3 | 对比度 | 正文 ≥ 4.5:1、大字 ≥ 3:1，四主题（sunny/care/night）逐一抽查 |
| L-A4 | 键盘 | 学习闭环全流程可纯键盘完成；焦点环可见 |
| L-A5 | 读屏（P1） | 关键流程 VoiceOver/NVDA 可完成；答题结果 aria-live 通报 |
| L-A6 | 动效降级 | `prefers-reduced-motion` 与家长开关下功能完整、无空白等待 |
| L-A7 | 光敏红线 | 全程无 > 3 次/秒闪烁 |

### 1.4 离线（P0）

| # | 验收项 | 通过标准 |
|---|---|---|
| L-O1 | 断网冷启动 | Service Worker 预缓存后，完全断网刷新可进入并完成学习闭环 |
| L-O2 | 资产本地化 | 字体/音效/笔顺数据/图标全部包内或 SW 缓存，运行时零第三方域名请求 |
| L-O3 | 弱网降级 | 未缓存的懒加载数据请求失败时给角色化提示并可重试，不白屏不崩溃 |
| L-O4 | 静态可部署 | zip 解压至任意路径的静态服务器可运行（相对 base，不依赖服务端路由） |

## 4. SOTA 对比基准（超越洪恩的量化定义）

| 维度 | 洪恩现状 | 我们的达标线 |
|---|---|---|
| 商业干扰 | 订阅墙/内购 | 零付费墙、零广告（C-1） |
| 主题 | 单一明亮主题 | 4 主题 + 字号 4 档（L-A3） |
| 无障碍 | 无读屏/无 reduced-motion | WCAG 2.1 AA 关键项（§1.3/§2.3） |
| 离线 | 需登录+大包下载 | 断网冷启动全功能（§1.4/§2.4） |
| 奖励动画 | 不可跳过 | 全部可跳过（L-F7/M-F7） |
| 家长数据 | 云端不可导出 | 本地持久化 + JSON 导出（L-F9） |
| 反馈延迟 | 约 100ms | ≤ 100ms 有测量记录（L-P6） |

## 5. 验收执行方法

1. `bash scripts/setup.sh && npm test && npm run build:all` —— C-3。
2. 解压 zip → `npx serve` → Lighthouse 跑分（移动模拟 + 4× 节流）→ 记录 L-P1–P4。
3. Performance 面板录制 60s 学习操作 → 核对 fps 与 long task（L-P5/M-P8）。
4. DevTools Network 切 Offline → 刷新 → 完成一个学习闭环（L-O1）；全程核对无外域请求（C-1）。
5. axe DevTools 全页扫描 + 键盘/读屏手动走查（L-A 系列）。
6. 家长面板逐项开关（主题/字号/音量/动效/时长）→ 刷新验证持久化。
7. 结果记入 `.agent_workspace/acceptance-log-round{N}.md`（每轮一份，含未达标项与责任模块）。
