# Round 11 离线 TTS 选型评估

> 决策日期：2026-08-27  
> 范围：快乐识字与 MathQuest 的普通话提示、单字、词句、绘本和学伴台词  
> 门禁标记：`ROUND11_H7`

## 1. 结论先行

Round 11 **不把 Piper 或通用 VITS 推理运行时直接塞进 1.0 安装包**。首选路线是“高频固定语料分批真人录音 + 现有系统 `SpeechSynthesis` 兜底”，同时做一轮受控的 Piper/VITS 样音盲测，只有在包体、授权、儿童音质三道门都通过后，才考虑把离线模型做成家长主动下载的可选语音包。首批录音覆盖单字标准音、核心操作反馈、错误鼓励与高频学伴句；含孩子名字、数量、连胜天数等动态插值句继续使用系统 TTS，并始终保留可见字幕和“家长读”降级。

这个选择不是认为神经 TTS 音质一定差，而是当前产品的主要缺口是**跨设备一致且可信的儿童教学发音**。录音可以用较小的首批资产，准确控制多音字、声调、停连、情绪与响度；模型方案则必须同时携带推理引擎、中文前端和至少一套声学权重，且引擎许可证并不能替代声音模型、训练数据与说话人权利审查。对当前不到 10 MiB 的发行预算而言，一份 63.2 MB 的普通话 Piper 权重已不是小增量。

## 2. 当前基线与需求边界

两款 App 现在都调用浏览器或操作系统的 `SpeechSynthesis`。识字侧会优先选择 `zh-CN`，检测不到中文嗓音时展示安装提示，并在字幕、家长读和无声路径之间降级；数学侧也不上传文本或音频。其优点是仓库和首包几乎没有 TTS 资产成本，缺点是 Android WebView、Windows、iOS 与不同厂商设备的声音、断句和可用性都不一致，甚至可能完全没有普通话嗓音。

语料不是单一形态：

1. **闭集、短且必须准确**：约 1800 个课程汉字、常用词、答对/答错/再试一次等反馈。最适合录音和逐条质检。
2. **闭集、长且需要表演**：绘本、成语、古诗、固定学伴台词。适合按课程批次录音，但需控制首包规模。
3. **开放或组合式**：孩子称呼、待复习数量、连续天数、动态题目。预录组合容易产生不自然拼接，适合 TTS 或改写为不含变量的固定句。
4. **无障碍提示**：必须以可见文本为主，语音失败不能阻断操作；TTS/录音都不是读屏语义的替代品。

因此不能用“一个声音方案包打全部场景”的口径选型。下面按包体、授权和音质三维比较首包部署，而不是只比较模型 demo。

## 3. 三维对比

|---|---|---|---|---|

### 3.1 包体判断

Piper 本质上也是 VITS 系模型的一种面向端侧的工程化路径，不能把“Piper”和“VITS”误算成两个完全不同的声学成本。以可核查的华研普通话 medium 权重为例，模型文件约 63.2 MB，还没有计入 ONNX Runtime、eSpeak-ng/音素化资源和 Android/iOS/Web 的桥接代码。即使商店允许更大的 AAB，首次下载、PWA 缓存、低存储设备与更新增量仍会受影响；把模型藏到动态 chunk 也只推迟下载，不会消除磁盘和授权成本。

真人录音也不能无限制全量铺开。若 1800 个单字每条成品平均 1.2 秒，加上头尾静音与索引，单字层约 36 分钟；32 kbps Opus 的纯码流约 8.6 MB，实际文件头、重复请求与分片会略高。首批不应一次录满全部长故事，而应依据调用日志的**本地匿名计数、人工课程优先级**和试用反馈选择 300–500 个高频单字、30–50 条固定反馈及核心新手引导。首包目标增量设为 ≤5 MiB；超出的绘本/成语旁白作为可删的课程语音包，不阻塞文本课程离线可用。

### 3.2 授权判断

需要审查四层，而不是只看 GitHub 顶部的 License：

1. **引擎代码**：维护中的 Piper 是 GPL-3.0；已归档 `rhasspy/piper` 是 MIT，但归档版本缺少持续安全维护，不能仅为宽松许可证永久冻结。
2. **运行依赖**：ONNX Runtime、音素化器、词典及原生二进制均须进入 SBOM 与 `THIRD_PARTY_NOTICES.md`，确认静态/动态链接和源码提供义务。
3. **模型与训练数据**：voice 文件的 `MODEL_CARD` 必须给出明确许可证、来源版本和哈希。“unknown”、非商业（NC）、仅研究或来源链接失效都直接 No-Go。
4. **声音人格权与儿童保护**：数据集许可不当然包含可合成任意新台词的声音权。真人录音与自训都要有演播者书面授权；不采集儿童试用者语音来训练，不以“反馈上传”暗中扩充语料。

若将来选 Piper，发布审查必须冻结引擎 commit、voice URL、SHA256、模型卡快照、训练集来源、许可证原文、NOTICE 与源码提供方式。未完成法律复核前只能内部评测，不能进入公开包。

### 3.3 音质判断

“听起来像真人”不是儿童教育唯一指标。候选声音要在同一台设备、相同响度下双盲比较，至少覆盖：

- 60 个单字：四声、轻声、易混淆声母韵母及“行、乐、长”等多音字；
- 20 个词句：数字、日期、连续标点、英文缩写和 `3 × 4 = 12` 等数学表达；
- 10 段长句：绘本对话、古诗停顿、鼓励与纠错情绪；
- 10 个异常输入：空白、emoji、生僻字、超长句，要求不崩溃且能降级。

由普通话教师 2 人给“字音/声调正确、断句、可懂度”打分，由 6–10 组家长与儿童给“自然、亲和、不吓人、愿意继续听”打分；所有样本先做响度归一，隐藏方案名称。硬门槛为关键单字严重读错 **0 个**、教师正确性均分 ≥4.7/5、儿童可懂度 ≥90%、低端 Android 首句 p95 ≤800 ms、连续十句无崩溃或明显爆音。模型即使平均 MOS 更高，只要关键字读错就淘汰；真人录音出现读错则重录，不靠后期变调掩盖。

## 4. 建议落地批次

### A 批：规范与 100 条金样

- 冻结文本 ID、展示文本、朗读文本、拼音/多音字语境、说话风格和目标时长；
- 录音采用同一演播者、麦克风、房间和工程模板，保留无损母带，发行转 Opus；
- 每条产物记录 `id/source/performer-contract/version/sha256/loudness/duration`；
- 100 条同时交给系统 TTS、Piper 候选和真人录音，执行上述盲测，不把内部模型带入发行包。

### B 批：高频固定语料

- 扩至 300–500 单字与固定教学反馈，目标首包增量 ≤5 MiB；
- 语音 manifest 以稳定文本 ID 查找，找不到、解码失败或用户关闭声音时回到当前 `speak()`；
- 每条必须有字幕；缓存失败、无网和权限拒绝不影响做题或阅读。

### C 批：课程下载包

- 绘本、成语、古诗按课程包拆分，家长区显示大小、来源、删除与重新下载入口；
- 下载前校验 SHA256，下载失败不自动切到在线 TTS 服务；保留系统 TTS/家长读；
- 只有试用反馈显示高使用率且包体预算允许时才扩充，不因“已经录了”强塞首包。

## 5. Go / No-Go 决策门

| 门 | Go 条件 | No-Go 触发 |
|---|---|---|
| 包体 | 首包语音增量 ≤5 MiB；完整单 App zip 仍 <10 MiB；低端机解码无卡顿 | 模型/运行时强制首包 >10 MiB，或缓存导致启动明显回退 |
| 授权 | 四层权利链齐全、SHA 与许可证冻结、法务复核通过 | 模型卡/训练集为 unknown、NC、research-only，或说话人授权缺失 |
| 音质 | 教师、儿童盲测及异常输入门槛全部通过 | 关键字严重错读、音色令儿童不适、长句稳定性不过 |
| 隐私 | 默认纯端侧；无儿童语音上传；下载由家长主动触发 | 静默联网合成、把试用录音用作训练、隐私页与实际行为不一致 |
| 可运维 | 稳定 ID/manifest、回退、删除、版本与哈希机制齐全 | 文案改动必须全量重发、坏资产阻断课程、无撤回机制 |

最终决策：**录音 B 批 Go；Piper 仅内部 A 批评测；通用/自训 VITS No-Go；任何模型公开分发均待授权与实测重新过门。** 现有 `SpeechSynthesis` 在过渡期保留，不把它宣传成“所有设备都有完全离线中文语音”，因为系统嗓音是否安装及其内部实现不由本项目控制。
