## 一、洪恩识字 / 洪恩数学 UI 优势分析

### 1.1 色彩策略

| 维度 | 洪恩识字 | 洪恩数学 | 可借鉴结论 |
|---|---|---|---|
| 主色 | 高饱和暖橙黄为核心，大面积明亮插画背景 | 深空藏蓝底 + 霓虹青/紫/金高亮 | 每个 App 一个强识别度的主题世界，主色占比 ≥ 60% |
| 色彩数量 | 单屏主色 3±1，功能色（对/错/奖励）全局恒定 | 同左，霓虹色仅用于可交互元素 | 严格限制同屏色相数，功能色语义永不漂移 |
| 视线引导 | 主按钮永远是画面中饱和度最高的元素 | 可点元素带辉光（glow），静态元素低饱和 | 用饱和度/辉光而非文字标注引导 3-6 岁视线 |
| 环节换色 | 字源环节转水墨古风、游戏环节转高饱和 | 每章星球一套配色变体 | 用色彩切换制造"环节仪式感"，帮助儿童感知阶段 |

**洪恩色彩弱点（我们的超越点）**：无系统性护眼/夜间模式；对比度未按 WCAG 校验（部分浅黄字压白底）；主题不可配置。

### 1.2 动画节奏

| 场景 | 洪恩实测节奏 | 设计启示 |
|---|---|---|
| 点击反馈 | < 100ms 内出现视觉 + 音效双反馈 | 反馈延迟预算 100ms，超过即"手感差" |
| 学习环节 | "玩认读练写测"每环节 30–90s，环节间过渡 1–2s | 短环节 + 过渡仪式感维持注意力，单任务不超 90s |
| 字源/概念动画 | 象形图→古文字→今字形变 2–4s，同步旁白 | 概念动画必须与语音同拍，长动画必须可跳过 |
| 奖励动画 | 星星/宝箱 1.5–2.5s，**不可跳过**（弱点） | 庆祝 ≤ 1.2s 主体 + 可跳过尾巴 |
| 空闲引导 | 约 5–8s 无操作后目标元素呼吸/发光 + 语音重提示 | 空闲提示是儿童产品刚需，节奏 6s/8s 双档 |
| 拖拽教具 | 磁性吸附、松手回弹、错放轻晃 | 物理感缓动（回弹/过冲）是"好玩"的核心来源 |

**洪恩动画弱点**：不支持系统"减少动态效果"；奖励动画不可跳过拖慢学习密度；低端机掉帧明显。

### 1.3 儿童友好交互

- **零阅读依赖**：全流程语音引导，图标 + 角色示范代替文字说明 —— 3-6 岁不识字用户可独立操作。
- **超大热区**：主要按钮估算 ≥ 64pt，拖拽目标更大且带吸附容错。
- **无惩罚反馈**：答错是摇头动画 + 温和音效 + 立即给提示，从不使用刺耳蜂鸣或倒扣。
- **单焦点原则**：同屏只有一个主要任务，装饰元素不可点或点击只有轻反馈。
- **IP 情感纽带**：固定角色贯穿全程（示范、鼓励、庆祝），建立陪伴感。
- **家长门**：家长设置入口用"按住 3 秒 / 算术验证"防儿童误入。

**洪恩交互弱点（超越点）**：订阅墙打断学习流；无键盘/读屏支持；离线能力弱、包体大；家长数据不透明不可导出。

### 1.4 超越策略总结

1. 保留：即时双反馈、短环节节奏、磁吸拖拽、语音引导、无惩罚反馈、家长门。
2. 超越：三主题（明亮/护眼/夜间）+ 数学太空主题；WCAG 2.1 AA 无障碍；`prefers-reduced-motion` 与手动开关；奖励可跳过；PWA 完全离线；本地数据可导出；零广告零订阅。

## 二、设计原则（五条铁律）

1. **100ms 双反馈**：任何点击在 100ms 内必须同时出现视觉与音效反馈。
2. **一屏一事**：儿童界面同屏仅一个主任务；次要功能收进家长面板。
3. **温和纠错**：错误反馈永远是"轻晃 + 柔和音 + 提示"，禁止红色大叉、蜂鸣、扣分动画。
4. **可跳过、可关闭**：所有 > 1.5s 的动画可跳过；音乐/音效/语音/动画均可独立关闭。
5. **令牌唯一源**：颜色、字号、时长、尺寸一律引用 `design-tokens.css` 变量，禁止硬编码。

### 3.2 语义色（随主题切换）

语义层是组件唯一可引用的颜色层（原始色板仅供主题层映射）：

`--bg-page` `--bg-page-solid` `--bg-blob-a/b/c`（背景装饰斑块）、`--surface` `--surface-strong` `--surface-sunken` `--surface-border`、`--text-strong` `--text` `--text-soft` `--text-invert`、`--brand` `--brand-strong` `--brand-soft`、`--accent` `--accent-soft`、`--success` `--danger` `--star` `--info`、`--grid-line`（田字格）、`--stroke-ink` `--stroke-hint`（笔顺墨色/底模）、`--focus-ring`。

### 3.3 四大主题

| 主题 | data-theme | 应用 | 定位 |
|---|---|---|---|
| 明亮童趣 sunny | `sunny`（默认） | 识字 | 暖橙黄渐变、白卡片，白天学习 |
| 护眼 care | `care` | 识字 | 米纸色低蓝光低对比，长时阅读/绘本 |
| 夜间 night | `night` | 识字 | 深蓝紫，睡前故事；亮度整体压低 |
| 深空 cosmos | `cosmos` | 数学（默认） | 星空底 + 霓虹交互色 |

规则：
- 主题切换必须在 300ms 内完成且不闪白（背景/文字带 `--dur-mid` 过渡）。
- 护眼模式下饱和度上限 70%，禁用辉光效果。
- 夜间/深空模式阴影改为纯黑系透明度，禁用大面积纯白 `#fff`（最亮用 `#f4f1ea` / `#f2f5ff`）。

### 3.4 对比度硬指标

- 正文（< 24px）对 surface：≥ 4.5:1；`--text-strong` 目标 ≥ 7:1。
- 大字（≥ 24px 或 ≥ 18.66px 加粗）：≥ 3:1。
- 图形/图标可辨识边界：≥ 3:1。
- 主按钮文字对按钮底色：≥ 4.5:1（洪恩浅黄字压白底的错误禁止出现）。
- 色彩永不作为唯一信息通道：对/错必须同时有形状（√/提示动画）+ 音效。

## 四、字体排印

### 4.1 字体栈

| 令牌 | 栈 | 用途 |
|---|---|---|
| `--font-round` | `'Nunito','PingFang SC','Hiragino Sans GB','Noto Sans SC','Microsoft YaHei',system-ui,sans-serif` | 界面/数字/按钮 |
| `--font-hanzi` | `'LXGW WenKai','Kaiti SC','STKaiti','KaiTi',serif` 回退 `--font-round` | 大字卡、笔顺展示（接近手写楷体） |
| `--font-num` | `'Nunito',ui-rounded,system-ui,sans-serif` + `font-variant-numeric: tabular-nums` | 计分、计时、算式 |

离线要求：正式包内置子集化 OFL 字体（Noto Sans SC / LXGW WenKai），禁止运行时请求 Google Fonts（见开源资源探针合规条目）。

### 4.2 字号阶梯（rem 基于 `body = 16px × --font-scale`）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--fs-xs` | 0.8rem | 家长面板辅助说明（儿童界面禁用） |
| `--fs-sm` | 0.9rem | 次要标签、pill |
| `--fs-md` | 1.05rem | 儿童界面正文下限 |
| `--fs-lg` | 1.2rem | 按钮、选项文字 |
| `--fs-xl` | 1.45rem | 区块标题 |
| `--fs-2xl` | clamp(1.8rem, 4vw, 2.3rem) | 页面标题 |
| `--fs-display` | clamp(2.4rem, 6vw, 3.4rem) | 结果页大数字/大标题 |
| `--fs-hanzi` | clamp(96px, 26vmin, 200px) | 单字大卡 |

行高：`--lh-tight:1.2`（大标题/大字）、`--lh-base:1.6`（正文）、`--lh-loose:1.85`（绘本）。
字重：`--fw-medium:500` `--fw-bold:700` `--fw-heavy:800` `--fw-black:900`；儿童界面最低 700，禁用 400 细体。
字号缩放：`data-font-scale = small(0.9) / normal(1) / large(1.14) / huge(1.28)`，家长面板可调。

### 4.3 汉字展示专项

- 大字卡必须置于田字格（`.tianzige`），格线用 `--grid-line` 虚线，格线对底色对比 ≥ 3:1。
- 笔顺：当前笔画高亮 `--brand`，已写笔画 `--stroke-ink`，底模 `--stroke-hint`；描红容错半径随年龄档可调。
- 拼音永远置于汉字正上方，字号 = 汉字的 22–28%，带声调标注。

## 五、布局、间距与断点

- **4pt 网格**：所有间距/尺寸是 4 的倍数。间距令牌 `--gap-2xs(4) --gap-xs(8) --gap-sm(12) --gap-md(16) --gap-lg(24) --gap-xl(36) --gap-2xl(48) --gap-3xl(64)`。
- **圆角**：`--radius-xs(8) sm(12) md(20) lg(28) xl(36) pill(999px)`——儿童产品无直角卡片。
- **页面容器**：`min(1080–1120px, 100%)` 居中；底部预留 ≥ 96px 给悬浮导航/安全区（`env(safe-area-inset-bottom)`）。
- **断点**：`480px`（手机竖屏紧凑）/ `640px`（手机横屏）/ `900px`（平板）/ `1200px`（桌面）。核心学习场景以**平板横屏优先**设计，手机竖屏降级为单列。
- **单焦点布局**：学习页结构固定为「顶部薄进度条 + 中央任务区（≥ 60% 视口）+ 底部操作区」。

## 六、动效系统

### 6.1 时长与缓动令牌

| 令牌 | 值 | 用途 |
|---|---|---|
| `--dur-instant` | 90ms | 按压反馈、涟漪起始 |
| `--dur-fast` | 160ms | 悬停、开关、chip 切换 |
| `--dur-mid` | 280ms | 页面过渡、卡片入场、主题切换 |
| `--dur-slow` | 520ms | 大元素入场、进度条增长 |
| `--dur-hero` | 900ms | 庆祝主体、关卡解锁 |
| `--stagger-step` | 70ms | 列表错落入场步进（60–90ms 区间取中） |
| `--ease-pop` | `cubic-bezier(0.34,1.56,0.64,1)` | 弹出过冲（back.out 同族） |
| `--ease-bounce` | `cubic-bezier(0.22,1.61,0.36,1)` | 更强回弹，奖励元素 |
| `--ease-smooth` | `cubic-bezier(0.45,0,0.25,1)` | 位移/页面过渡 |
| `--ease-anticipate` | `cubic-bezier(0.36,0,0.66,-0.36)` | 退场前蓄力 |

GSAP 对应：入场 `back.out(1.35)`、庆祝 `back.out(1.8)+bounce.out`、错误 `power2.out`（与 `shared/utils/animations.js` 预设一致）。

### 6.2 节奏编排（Choreography）

| 事件 | 编排 | 总时长 |
|---|---|---|
| 按压 | 缩放 0.96 + 阴影下沉 | 90ms 按下 / 160ms 回弹 |
| 答对 | 选项弹跳（bounce 高度 20px）→ 星星 pop → 音效同拍 | ≤ 600ms |
| 答错 | 选项左右轻晃 ±12px，同时语音提示 | 420ms |
| 页面切换 | 旧页上移淡出 280ms，新页下入淡入 280ms（重叠 80ms） | ≤ 480ms |
| 列表入场 | y+28 → 0，错落 70ms/项，上限 8 项参与动画 | ≤ 1.1s |
| 庆祝（过关） | 角色跳跃 + 星星三连 pop（stagger 60ms）+ 彩带 | 主体 ≤ 1.2s，尾部粒子可被点击跳过 |
| 空闲引导 | 6s 无操作：目标呼吸（scale 1↔1.04, 1.6s 循环）；8s：语音重提示 | 循环 |
| 概念演示（字源/数形） | 与旁白逐句同步，每段 2–4s | 全程可跳过 |

### 6.3 动效红线

- 同屏循环动画 ≤ 2 个；装饰性无限循环仅允许 `float-y` / `wiggle` 幅度 ≤ 10px/2°。
- 全部动画只用 `transform` + `opacity`（不触发 layout/paint）；持续动画元素加 `will-change` 并在结束后清除。
- 任何 > 1.5s 的序列必须响应点击跳过；跳过后状态与播完完全一致。
- `prefers-reduced-motion: reduce` 或 `data-motion="reduced"`：所有动画压至 0.001ms、循环 1 次，庆祝降级为静态星星 + 音效；家长面板可强制 `data-motion="full"` 覆盖系统值。
- 无 3 次/秒以上的闪烁（光敏性癫痫红线）。

## 七、组件规范

### 7.1 按钮

| 规格 | 高度 | 最小宽 | 字号 | 场景 |
|---|---|---|---|---|
| `--btn-h-sm` 44px | 44 | 44 | `--fs-sm` | **仅家长面板** |
| `--btn-h-md` 56px | 56 | 56 | `--fs-lg` | 儿童界面默认（= `--tap-min`） |
| `--btn-h-lg` 68px | 68 | 96 | 1.2rem | 主操作 |
| `--btn-h-hero` 84px | 84 | 160 | 1.35rem | 首页/结果页 CTA |

- 形态：药丸圆角（`--radius-pill`）+ 底部 3px 压边阴影（`--shadow-press`），按下位移 3px 模拟实体按键。
- 相邻可点目标间距 ≥ 8px；图标按钮最小 56×56。
- 主按钮同屏唯一，使用 `--brand` 渐变；次按钮 `--accent`；幽灵按钮仅家长面板。

### 7.2 学习交互组件

- **答题选项卡**：最小 96×96（`--quiz-option-min`），命中区可比视觉大 8px（hit-slop）；选中态描边 3px `--brand` + pop 动画。
- **拖拽教具**：拖拽物 ≥ 96px；磁吸半径 ≥ 24px（`--snap-radius`）；抬起吸附 160ms `--ease-pop`；错放回弹 280ms 并轻晃。
- **进度条**：高 14px（`--progress-h`）药丸形，增长动画 `--dur-slow`，节点用星星标记。
- **星级**：星星尺寸 44px（`--star-size`），点亮顺序 stagger 60ms，配升调三连音。
- **田字格书写区**：`clamp(220px, 60vmin, 420px)` 正方形，永远整格可见不裁切。
- **关卡地图节点**：≥ 72px 圆形，当前关辉光呼吸，锁定关去饱和 + 锁图标（不可点时不给音效反馈误导）。

### 7.3 弹层与家长门

- 模态：圆角 `--radius-xl`，遮罩 `rgba(20,15,8,0.45)`（暖）/`rgba(3,6,24,0.6)`（深空），入场 scale 0.9→1 `--ease-pop`。
- 家长门：进入家长面板需「按住 3 秒」或「两位数乘法口算」验证；儿童侧永不出现外链/支付/评分弹窗。
- Toast：顶部下滑，2.4s 自动消失，同屏最多 1 条，带 `aria-live="polite"`。

## 八、音效反馈系统

### 8.1 事件—音效映射

| 事件 | 音色设计 | 时长 | 增益（相对） |
|---|---|---|---|
| 点击/tap | 短促木鱼/水滴单音 | ≤ 120ms | 0.6 |
| 答对 | 明亮大三和弦上行琶音 | 300–500ms | 0.8 |
| 答错 | 两音下行（大二度），圆润正弦，**禁止蜂鸣** | 250–400ms | 0.5 |
| 星星点亮 | 升调三连铃音（与 stagger 同拍） | 3×140ms | 0.8 |
| 过关庆祝 | 短号角/竖琴刮奏 | 1–2s | 0.9 |
| 拖拽吸附 | 轻"咔哒" | ≤ 80ms | 0.5 |
| 翻页/切换 | 轻扫风声 | ≤ 200ms | 0.4 |

现有 `shared/assets/audio/{tap,success,try-again}.wav` 为合成占位，正式版按上表参数重制（合成或 CC0 采样）。

### 8.2 语音引导（Voice Guidance）

- 每个学习页进入时自动播报任务（≤ 6s）；常驻"小喇叭"重播按钮（56px）。
- 空闲 8s 语音重提示（换一种说法，最多 2 次，避免机械重复）。
- 答错语音给**可操作提示**（"再听一遍？它是三声哦"），不评判（禁止"你错了"）。
- 语音期间 BGM/音效 duck 至 30%（`--voice-duck: 0.3`）。

### 8.3 混音与工程规则

- 三条独立总线：BGM（`--bgm-gain: 0.35`）、SFX（`--sfx-gain: 0.7`）、Voice（`--voice-gain: 1.0`），家长面板独立开关 + 持久化。
- SFX 播放延迟 < 100ms：预解码 AudioBuffer，禁止播放时 fetch。
- 遵守浏览器自动播放策略：首个用户手势解锁 AudioContext；解锁前静默不报错。
- 同类 SFX 100ms 内去重（防连点爆音）；所有音量变化用 20ms ramp 防爆点。
- 全部音效素材响度归一（峰值 -3dBFS 内，响度对齐），禁止个别刺耳。

## 九、无障碍与包容性

1. 触控目标 ≥ 56×56 CSS px（超过 WCAG 2.5.5 的 44px）；间距 ≥ 8px。
2. 全键盘可达：Tab 顺序 = 视觉顺序；`:focus-visible` 3px `--focus-ring` 外描边。
3. 读屏：交互元素有中文 `aria-label`；答题结果用 `aria-live` 通报；纯装饰元素 `aria-hidden`。
4. `prefers-reduced-motion` / `prefers-contrast` 响应 + 家长面板手动档。
5. 对比度按 §3.4 执行；色彩非唯一通道。
6. 语音/字幕互补：语音引导同时有图标示意；绘本朗读逐句高亮。
7. 左右手无差别布局：关键操作不固定单侧；拖拽均可用"点选 + 点放"两步替代完成。

## 十、状态与反馈

- **加载**：> 400ms 的等待必须出现骨架或角色小动画；> 3s 显示进度说明。禁止白屏。
- **空态**：插画 + 一句鼓励 + 一个明确 CTA（如"开始今天的第一个字"）。
- **错误**（技术性）：儿童侧只显示"哎呀，休息一下再试"（角色化），家长面板可见技术详情。
- **成功密度**：每 3–5 次交互至少一次正向强化（星星/语音夸奖），夸奖语随机池 ≥ 8 条。

## 十一、令牌落地方式

1. `shared/styles/design-tokens.css` 是唯一令牌源：原始色板 + 语义层（4 主题）+ 排印 + 间距 + 动效 + 组件 + 音频常量。
2. 两 App 在入口 CSS **最先** `@import` 该文件（Vite alias `@shared` → `../../shared`，或相对路径）。
3. literacy-app：`theme.css` 与令牌文件重复的变量在 Round 2 删除，仅保留 App 专属覆盖。
4. math-app：根元素挂 `data-theme="cosmos"`；令牌文件内已提供其现用变量（`--space-0..3`、`--ink*`、`--cyan` 等）的兼容别名，Round 2 迁移到语义令牌后移除别名。
5. JS 读取音频/动效常量：`getComputedStyle(document.documentElement).getPropertyValue('--sfx-gain')`，保证 CSS/JS 单一事实源。
