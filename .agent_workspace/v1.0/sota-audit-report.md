## Changes made in this round

1. **A7 (TPDF dither spectrum) promoted to a hard pass.** `tools/generate_v1_evidence.py`
   measures `quantize_with_tpdf` at 16 bits and publishes
   `.agent_workspace/v1.0/tpdf-spectrum-report.json`: total error RMS -96.335 dBFS against
   the LSB/2 theoretical -96.33 dBFS, spectral flatness 0.99, largest error-spectrum spur
   1.8 dB over the median (vs 29.1 dB for the undithered quantizer), and the
   `tests/test_dither.py` silence-tail bound (noise present, ≤1 LSB peak).
2. **B5 (spectral edit + DeClick/DeHum/NR) promoted to a hard pass.** The verifier now
   asserts the modules that actually landed: `DeClickEffect`/`DeHumEffect`/
   `NoiseReduceEffect` in `audio_studio.dsp.repair` and `attenuate_band`/`remove_band`/
   `apply_spectral_gain` in `audio_studio.dsp.spectral_edit`.
3. **B6 (plugin host, state, PDC) promoted to a hard pass on mock evidence.** The verifier
   asserts the host API (`PluginHost.state_blob`/`restore_state`/`latency_samples`,
   `LatencyCompensator`, `PluginEffectAdapter`) and reads
   `.agent_workspace/v1.0/plugin-host-report.json`, generated by driving three in-process
   mock hosts through load/process, state save/restore, and a sample-exact PDC null test.
   The report carries `evidence_type: mock-host` and the verifier asserts that field —
   real-VST3 binary compatibility evidence remains explicitly out of scope of this pass.
4. **B7 (10-file -16 LUFS FLAC batch) promoted to a hard pass.** The real CLI
   (`python -m audio_studio.batch.cli --lufs -16 --format flac`) was run over 10
   synthesized WAV files; every FLAC output re-measures at -16.0 LUFS exactly
   (`.agent_workspace/v1.0/batch-loudness-report.json`, max error 0.0 LU).
5. **D5 (UI scaling 100%–200%) promoted to a hard pass.** The verifier exercises
   `audio_studio.app`'s scaling contract (bounds 1.0–2.0; 100/125/150/175/200% all parse;
   the factor is published to `QT_SCALE_FACTOR`) and pins the end-to-end Qt probe in
   `audio-studio/tests/test_accessibility.py::TestScaleFactor`.
6. **B1 (M1–M13 evidence) gets its manifest.**
   `.agent_workspace/v1.0/sota-evidence-manifest.json` maps every must-have requirement to
   concrete evidence: 9 of 13 pass, 4 remain partial (see below). B1 stays xfail with the
   partials named in the reason.
7. Parallel Round D branches promoted **A6** (true-peak limiter ISP ceiling,
   `.agent_workspace/v1.0/limiter-isp-report.json`), **D2** (dock-layout persistence), and
   **D3** (keyboard-only workflow), and landed passing evidence for **A5** (soxr VHQ SRC:
   stopband -160.3 dBFS, THD+N -155.4 dBFS), **C1** (30-minute soak), and **C3**
   (callback timing) — the latter three currently report as XPASS.
