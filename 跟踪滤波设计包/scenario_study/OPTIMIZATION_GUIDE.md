本指南的每一个数字都来自可复跑的仿真：

```bash

python3 validate_realistic_scenarios.py          # 26/26 检查通过, ~21 s

# MATLAB/Octave 同款（同种子、同判据, 124 个 KEY 指标与 Python 一致）
cd ../matlab/scenario_study
octave --no-gui --eval "rc = validate_realistic_scenarios(); exit(rc)"
```

前端模型规则（审计修正）：前端是固定硬件，86 MHz 物理前端模型只在**信号的
多普勒谱超出 40 MHz 噪声带模型**时启用——fD_peak = 2·v_peak/λ > 20 MHz（即
v_peak > 15.5 m/s），与振动频率无关（100 kHz/20 mm/s 的 fD 仅 25.8 kHz，
仍用 40 MHz 噪声带模型）。

场景定义：零差 S1（工况地图）/ S2（散斑矩阵）/ S3（瞬态与换档）/ S4（多表面
切换）/ S5（最坏角点）；外差 H1（量程-速度地图）/ H2（超 f_3dB）/ H3（浴缸
边界）/ H4（弱回光）；交叉对照 X1。完整表格见

## 1. 哪些场景是瓶颈（仿真数字总表）

| 场景 | 关键实测数字 | 限制机理 | 严重度 |
|---|---|---|---|
| S1 (100kHz, 20 m/s) | phi_err = **1.001 rad**，恰好压在 1 rad 守卫线上 | FAST 档 fn=1.6 MHz 对用户高速角点刚好不够；幅值刻度仍为 0.00%（公共窗定标），但载波路径（NCO 输出）随 phi_err 恶化 | **高**：守卫边界横穿用户 20–30 m/s 工作区 |
| S1 (100kHz, 30 m/s) | phi_err = **1.501 rad**，OVERRANGE；clean ampErr 仍 -0.00% | 同上，降级区仍可测幅值，但必须上报 overrange 标志 | **高** |
| S1e 动态抽查（30 m/s FAST 格点） | 静态载波缓存 +50.6 dB，**真实运动下动态增益 -1.8 dB（10kHz/30m/s）与 -15.0 dB（100kHz/30m/s）**——坍缩 >52 dB；用户点 100kHz/20mm/s 动态 +42.3 dB 与静态 +43.3 dB 一致 | 真实运动把环推入点击高发区（np 数百–数千/0.5ms），且 FAST 的 B_loop=7.1 MHz > B_WIN=4 MHz 点击直通全输出；S1 地图的 stG 列只能当场景无关上界读 | **高**：30 m/s 弱光角点的带内 SNR 优势在动态下不存在 |
| S2 (tau_c=20us, CNR=3dB) | lock **43.2%**（tau_c=50us 时 51.5%，100us 时 80.4%） | 门控按设计在散斑深衰落中放开（invalid 标志）——不是滤波缺陷，是可用数据比例受物理限制 | 中：低 CNR + 快散斑时可用数据减半 |
| S3 T3（错档暴露窗） | 旧档 SLOW 在 30 m/s 上 ampErr **-96.2%**、near-pi **5109** 次；正确升档（T2）为 +0.00% / 0 次 | 换档只在选档更新时刻生效，选档更新周期就是唯一暴露窗 | **高**（若固件选档慢）/ 低（若即时） |
| S4 多表面 | 每边界 relock 中值 **33.6 / 35.0 us**（预算 80 us）；三段 ampErr ≤0.7% | SLOW 档重捕时间 = acq_time(4·tauF=32us) + 门控检测延迟 | 低：有裕量 |
| S5 最坏角点（100kHz/30m/s + 散斑 50us + CNR 3dB） | LOCK 样本 ampErr **-33%**（全窗 -50%）；lock 76.5%；净条纹漂移中值 **264 周/0.5ms** | 三重叠加：overrange 档 + 散斑掉落 + 弱光。位移积分在该角点无效，幅值只在 LOCK 样本上有界可用 | **高**（物理极限，须靠上报而非参数补救） |
| H1/H2 (5 MHz) | SLOW 未校正幅值比 **0.016**、FAST **0.172**；FAST+频响校正后 **-1.64%** | 外差档位=测量带宽（f_3dB=2.058·fn），超带只能 FAST+|H_L| 校正 | 中：5 MHz 只有一条可用路径 |
| H3 浴缸谷底 | v_pi 谷值 SLOW/MEDIUM/FAST = **79 / 250 / 790 mm/s**（0.5·v_pi 全过、2·v_pi 全滑周） | 卷绕线（e=pi）实测被夹逼在 2 倍以内 | 中：高频+大速度需按档查浴缸图 |
| 硬边界（外差） | v_if = **3.01 m/s**（IF 频偏窗）、v_alias = 7.91 m/s | 与档位无关的体系结构上限 | **高**：>3 m/s 外差直接出局 |

结论：对用户的 30 m/s / 100 kHz 应用，**真正的瓶颈只有两个**——
(1) S1/S5 的 FAST 档 phi_err 超守卫（1.0–1.5 rad），S1e 的动态增益坍缩
（点击直通）是它的另一面实测证据；
(2) S3 的换档即时性。其余场景要么有裕量（S4），要么是物理极限（S2/S5 的散斑
与弱光），参数怎么调都换不来，只能靠 invalid/overrange 上报与光学侧改善。

## 2. 可调旋钮按影响排序（含代价）

按对用户工况的实测影响从大到小：

### #1 档位 fn（含选档即时性）——影响最大

* **选档即时性**：T3 实测错档 = **-96.2% 幅值 + 5109 次 near-pi**，正确升档
  = 0.00% / 0 次。选档更新周期是唯一暴露窗（validate_app A3 的实测版）。
  固件必须保证 v_peak/f 估计到升档生效 ≤ 1 个选档周期，升档路径不允许迟滞
  （迟滞只用于降档防抖，`select_band_hysteresis` 已实现该不对称性）。
* **FAST 档 fn 上调（或加 FAST+ 档）**：phi_err ∝ 1/fn²。
  fn 1.6 → 2.0 MHz 时 (100kHz, 30m/s) 的 phi_err 从 **1.50 → 0.96 rad**
  （回到守卫内）；代价 B_loop 从 7.08 → 8.85 MHz，环内 CNR 损失仅
  **-0.97 dB**（86 MHz 前端下环内 CNR@3dB 从 10.8 → 9.9 dB，仍在点击门限
  之上——S1 实测 86M 前端三档**静态载波**增益趋同 ~+50 dB 支持这一裕量判断；
  但 S1e 动态抽查显示真实 30 m/s 运动把 FAST 环推入点击高发区、动态增益
  坍缩到 -2…-15 dB——把 phi_err 拉回守卫内正是降低动态点击率的第一手段，
  这让 FAST+ 档的必要性更强而不是更弱）。
  这是本套件给出的**性价比最高的单一改动**。

### #2 门控 tauP/tauF——重捕时间与误放开的直接权衡

* S4 实测 relock 中值 33.6/35.0 us，其中 32 us 就是 SLOW 的
  acq_time = 4·tauF（tauF=8us）。tauF 减半 → relock ≈ 17–19 us。
* 代价：更短的确认时间在散斑深衰落中更易假重捕。S2 中 CNR=3dB 的 lock 已只有
  43.2–80%（tau_c 20–100us），tauF 过短会把这些边缘衰落变成
  锁定-掉落抖动。建议只对 MEDIUM/FAST（本来 tauF=2/1us）动手，SLOW 保持 8us。
* 门限 snr_on/snr_off（1.0/0.3）与 rel_on/rel_off（0.20/0.08）在 S4 中验证了
  "段间 6dB 幅值跳变不触发门控、-30dB 缝隙可靠触发"——不要动它们，除非实机
  测得的表面反差谱与 12/6/3dB 假设差别很大。

### #3 B_WIN（公共残差测量窗，4 MHz）——输出噪声与带宽的直接换算

* S1 实测：full 输出幅值误差与档位/phi_err 几乎无关（0.00%），因为刻度由
  公共 4 MHz 窗定标——这是设计意图，也意味着 B_WIN 是输出噪声的第一旋钮。
* 用户典型 f ≤ 100 kHz：B_WIN 4 → 1 MHz 可把窗 ENBW 从 7.8 → 1.95 MHz，
  输出带内噪声再降 **~6 dB**，代价平坦区从 ~3.6 MHz 缩到 ~0.9 MHz（对
  100 kHz 应用没有损失，对仪器 3 MHz 满量程模式不可用——应做成模式选项而非
  全局改动）。

### #4 zeta（环路阻尼，1.2）——次要，且有反面

* B_loop 系数 = pi(1+4·zeta²)/(4·zeta)：zeta 1.2 → 0.8 时 4.42 → 3.50
  （-21%，环内 CNR +1.0 dB）。
* 反面：阻尼下降使瞬态过冲变大。S1 中 (10kHz, 20 m/s) 的 MEDIUM 档
  phi_err=0.918 rad 已贴守卫线，过冲裕量比 1 dB 环内 CNR 更值钱
  （validate_zeta_sweep 的结论也是输出平坦度由窗决定、zeta 只影响载波路径）。
  **建议保持 1.2 不动。**

### #5 PHI_GUARD（1.0 rad）——上报线，不是动态旋钮

* 守卫只决定"选哪个档 + 是否上报 overrange"，不改变环路动态。放宽到 1.2 rad
  可把 (100kHz, 20m/s) 划回守卫内，但 S1 的 ampErrNCO 列显示载波路径误差随
  phi_err 单调增长——放宽守卫只是把降级藏起来。**保持 1.0 rad**，把 #1 的
  FAST+ 档做出来才是正解。

## 3. 对 30 m/s / 100 kHz 应用的具体建议（按优先级）

1. **加一个 FAST+ 档：fn ≈ 2.0 MHz**（tauP/tauF 沿用 FAST 的 1us/1us）。
   收益：整个 20–30 m/s × ≤100 kHz 角点回到守卫内（1.50 → 0.96 rad）；
   代价 -0.97 dB 环内 CNR。选档表在 v_peak > ~18 m/s 时指向 FAST+。
2. **固件换档路径**：升档必须在下一个选档更新即生效（T3 实测轨迹
   SLOW→FAST 就是这个行为，S3c 检查它——T2 的 FAST→FAST 不构成检验）；
   选档周期建议 ≤ 100 us（一个 S4 段长的 2/3），错档
   暴露每多 1 个周期就是 T3 那种 -96% 的数据段。
3. **上报语义**：overrange（phi_err > 1 rad）与散斑 invalid（gate 非 LOCK）
   必须同时、独立上报。S5 实测：只取 LOCK 样本幅值误差 -33%（有界可用），
   混入 invalid 样本变 -50%（不可用）；净条纹漂移 264 周/0.5ms 说明该角点
   **位移积分必须禁用**，只输出速度/幅值 + 两个标志。
4. **CNR 指标定义在实际前端带宽上**（86 MHz），不要沿用 40 MHz 噪声带模型
   的数字：S1 实测同一 "CNR=3dB" 下 FAST 档静态载波增益 +12 dB（40M，点击
   门限之下）vs +50.6 dB（86M，门限之上）——规格书里的 CNR 若定义错带宽，
   性能预测会差一个量级（validate_app A6 的结论，本套件在整张地图上复测）。
   同时注意 S1e：静态载波数字是场景无关上界，30 m/s 动态下 FAST 格点
   实测坍缩（-2…-15 dB），规格书不能把 stG 列当动态 SNR 承诺。
5. **如果输出带宽可以按应用收窄**：做一个 B_WIN=1 MHz 的"结构模式"，
   100 kHz 应用直接再拿 ~6 dB 输出噪声（见 #3 旋钮）。
6. **散斑对策在光学侧**：S2 表明 CNR=3dB 时无论怎么调参 lock 只有 43–80%。
   提高回光 CNR 到 12 dB（lock 85–91%）或做空间分集（QTec 联合深衰落概率
   (1-e^-F)^M，见 fig3）比任何滤波参数都有效。

## 4. 实机上要测什么（闭合仿真与硬件的差距）

仿真里被"假设"的、实机必须实测校准的量，按重要性：

1. **前端噪声 ENBW 与 PSD 形状**：本套件的 86 MHz+线性相位 LPF 是模型
   （A6 v2）。实测 AFE 的等效噪声带宽、通带内群延迟纹波；CNR 的规格定义带宽
   随之固定下来（见建议 4）。
2. **滑周门限曲线**：FAST 档在环内 CNR ≈ 7.5 dB（40M/CNR3）与 10.8 dB
   （86M/CNR3）之间跨过点击门限（静态增益 +12 → +50 dB）。实机测滑周率 vs
   环内 CNR 曲线，确认门限位置与指数斜率——它决定 FAST+ 档的 -0.97 dB
   代价是否真的无害。**并且要在真实运动下测**：S1e 实测 30 m/s 正弦运动
   把 FAST 环的 near-pi 事件从静态 ~0 推到每 0.5 ms 数百–数千次，
   动态点击率才是产品角点的真实指标。
3. **目标表面的散斑统计**：tau_c 分布与深衰落深度（S2 假设高斯谱、1/e@tau_c）。
   用实测 tau_c 重跑 S2 矩阵即可得到真实 lock%/位移 rms 预算。
4. **门控阈值 vs 真实表面反差**：S4 假设段间 12/6/3 dB、缝隙 -30dB/20us。
   实机扫描典型工件（反光膜→黑漆→远距），记录 C/Cref 轨迹，校准
   rel_on/rel_off 与 relock 时间（仿真预测 33–35 us）。
5. **固件选档延迟**：从 v_peak 估计变化到新档系数生效的实测延迟（S3 的
   暴露窗）；连同 v_peak 估计器的响应时间一起测。
6. **外差专项**（若用外差）：IF 中心漂移与 AOM 相位噪声（仿真固定
   +20 kHz 偏置）；在振动台上按 H2 的方法实测 |H_L(f)| 校正表；弱回光
   底噪下降对照 H4 的 ~15 dB。

## 5. 决策树：什么时候用零差，什么时候用外差

以下每条分支都有本套件的实测数字支撑：

```
你的峰值速度是多少？
├─ > 3.0 m/s ──────────────► 只能零差。
│                            外差硬边界 v_if = 3.01 m/s（IF 频偏窗，H1 表头），
│                            与档位无关；零差 30 m/s 时 fD=38.7 MHz 仍在
│                            43 MHz 信号通带内（S1 全表实测）。
├─ ≤ 3.0 m/s，继续：
│  你的振动频率是多少？
│  ├─ > 3 MHz（例如 5 MHz 表面波）──► 外差 FAST + |H_L| 频响校正。
│  │       H2 实测：校正后 -1.64%；零差仪器带宽止于 3 MHz
│  │       （公共窗平坦区 ~3.6 MHz）。
│  ├─ ≤ 100 kHz 结构/低频，要最高灵敏度 ──► 零差 SLOW。
│  │       X1 同一运动实测：零差 SLOW SNR gain +43.3 dB（40M 噪声带参考系,
│  │       20 mm/s 的 fD=25.8 kHz 不触发 86M 物理前端；S1e 动态复核 +42.3 dB）,
│  │       且换档不改变测量带宽；外差同点 +30.5 dB（19M 前端参考系）。
│  │       注意 X1 的苹果/橘子注记：两个数字各自相对自己的 OFF 参考，
│  │       不能直接相减，但"都 >+10dB 门限扩展、幅值刻度都保持"是公平结论。
│  └─ 中间频段：两者都可 ──► 看下一问。
│     回光有多弱、表面多不配合？
│     ├─ CNR 常年 ≤ 4 dB、散斑严重 ──► 零差 + 分集/更大接收孔径优先
│     │       （S2：CNR3 lock 只有 43–80%，问题在光子不在滤波；
│     │        外差同样受限，H4 的 15 dB 底噪下降不改变谱线 SNR）。
│     └─ CNR ≥ 12 dB ──► 哪个都行；选系统集成更简单的一侧：
│             零差：需要椭圆标定（g, delta 出厂一次），DC 附近有方向信息;
│             外差：天然无 DC 漂移问题，但档位=测量带宽（H2），
│             大速度谷值按 H3 浴缸图查（79/250/790 mm/s @ f=fn）。
└─ 既要 30 m/s 又要 5 MHz：本套件没有这个角点的可行解——
   零差带宽止步 3 MHz，外差速度止步 3 m/s。需要分光路双系统。
```

## 6. 本指南数字的可信度边界

* 所有零差增益数字基于 R1–R4 公平规则（信号增益近无噪测、噪声降静态载波
  测、中值统计）；不同前端带宽（40M vs 86M+L）的增益**不可跨列相减**
  （S1 说明3）。
* S5 的 -33% / 264 周是"有界诚实报告"：它说明该角点产品必须降级上报，
  而不是滤波器可以调好的工作点。
* S1 地图的 stG 列是 R2 静态载波方法（场景无关缓存），已在表头/说明中
  明确标注；S1e 抽查给出 3 个格点的全动态实测——用户点两者一致（差 ~1 dB），
  30 m/s FAST 格点动态坍缩（静态值只是上界）。
* Python 与 MATLAB/Octave 两套实现同种子逐位一致（124 个 KEY 指标全部在
  5% 容差内，最大相对偏差 0.86%），Windows MATLAB 无需 MEX 即可复跑。
