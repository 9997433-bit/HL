# 外差电 IQ 证据等级与待补仿真（来自代码审计）

## 已数值支撑（E2）
- 纯 NCO 输出、禁 +g·e 前馈、禁 w 连续增益
- 外差下固定 preLP 幅值崩溃、PLL 保信号（H4 / t5）

2. 外差验证多用 `gate='always'`，三态门控+散斑 MC 不足（nseed<200）
3. ceiling 公式与 welch 局部带测量口径未闭合
4. f_acc_cap=100kHz、MEDIUM=10% 为 [自研] 初值
5. A1/A2（单旋钮 vs 双旋钮）待实机判决

## 下一步仿真优先级
1. IF 带通 + 实 ADC + NCO 下变频全链
2. 外差 gate=auto + 散斑 MC ≥200 种子
