# 零差 IQ 椭圆标定操作指南（硬件不可改）

λ = 1550 nm（本包默认）。信号模型：

```
u = A·cos(φ) + p
v = B·sin(φ + δ) + q
g ≡ B/A = 1 + ε        （增益比，ε 为增益失配）
φ = 4π·x/λ + ψ         （x 为位移，ψ 为工作点/慢漂）
```

---

## 1. 标定什么、标定几次

| 参数 | 物理含义 | 是否随表面/距离/振动变 | 标定频率 |
|------|----------|------------------------|----------|
| **g、δ**（或 A、B、δ） | IQ 链路增益比、正交误差 | **基本不变**（仪器常数） | **出厂/台架 1 次**，写入 NVRAM |
| **p、q** | 直流偏置（含随回光功率变的分量） | **随工况跳变** | **在线快跟**，每次换表面/距离自动更新 |
| **R**（回光幅度） | √(I²+Q²) 的标度 | 随表面、距离变 | 实时估计，不写入标定文件 |

**重要结论**

- **不需要**每次测量前做大振动标定；也**不依赖**现场有大振动。
- 没有出厂 g、δ 时，可用静置温漂（方法 B）兜底，但收敛慢、精度不如出厂标定。
- 振动大小只影响「能不能从数据里拟合椭圆弧」，**不改变** g、δ 的真值。

---

## 2. 出厂/台架标定 g、δ（三选一，按优先级）

### 方法 A：激光调频扫条纹（精度最高，需激光电流/温度可调）

**前置条件**

- 激光器频率可通过电流或温度调制（DFB 通常可以；HeNe 通常不行）。
- 测量期间目标静止。
- 已知单程光程差 L_imb（m）；扫一条纹所需频移 Δν₂π = c / (2·L_imb)。
  - 例：L_imb = 1 m → 约 150 MHz；L_imb = 0.2 m → 约 750 MHz。

**操作步骤**

1. 目标静止，关闭振动激励。
2. 以 1–5 Hz 三角或锯齿扫激光电流/温度，扫过 ≥ **3 个条纹**（相位变化 ≥ 6π）。
3. 同步采集 I、Q（与测量同采样率，直流耦合，禁止 AC 耦合）。
4. 对整段数据均匀抽稀至 ≤ 8000 点，调用 `heydemann_fit(u, v)`。
5. 检查合格判据（见 §2.4）；通过则写入 NVRAM，**只存 A、B、δ**（或 g=B/A、δ），**不存** p、q。

**数据量**：≥ 3 条纹，建议 10–30 s；前端 CNR ≥ 20 dB。

---

### 方法 B：自然漂移扫弧（无调频、无大振动时的台架标准做法）

**前置条件**

- 回光幅度在标定段内相对稳定（|R| 变化 < ±5%，散斑慢漂可接受）。
- 工作点 ψ 能慢漂：温漂、气流、轻触底座均可；**不需要振动**。

**操作步骤**

1. 目标静止（或加极小激励 < 20 nm，仅用于确认链路通，不参与拟合）。
2. 静置 **5–30 分钟**，让 ψ 自然漂移。
3. **分块求块均值**（关键：块长 ≫ 振动周期、≪ 漂移时间）：
   - 100 Hz 振动：块长 **100 ms**（含 10 个周期）。
   - 无振动：块长 **50–200 ms** 均可。
4. **幅度门控**：保留块功率在段内中位数 ±5% 以内的点；变幅块丢弃。
5. 当累计块均值点覆盖弧 **≥ π/2 rad** 时，对块均值序列做 `heydemann_fit`。
6. 通过后只将 **A、B、δ** 写入 NVRAM。

**数据量**：覆盖弧 ≥ 1.57 rad；块点数 ≥ 12；建议总时长 10–30 min（漂移快可缩短）。

---

### 方法 C：现场大振动机会标定（可选，非必须）

若某次测量本身振幅大（例如反光膜、> 300 nm、多条纹），可在**正常输出位移的同时**后台拟合 g、δ，无需停机。

- 判据：相干振幅对应相位摆幅 m = 4πA/λ ≥ 2 rad，且 CNR ≥ 25 dB。
- 用该段 `fit_arc_gated` 更新 A、B、δ，写入 NVRAM 作定期复核。
- **没有大振动时跳过即可**，不影响日常测量（依赖出厂 g、δ）。

---

### 2.4 合格判据（三种方法通用）

拟合返回 `res` 字典，**全部满足**才接受：

| 指标 | 门限 | 含义 |
|------|------|------|
| `res.ok` | `True` | 98% 稳健覆盖弧 ≥ π/2 |
| `res.arc` | ≥ 1.57 rad | 相位多样性足够 |
| `res.rms` | < 0.05 | 圆化后径向残差 RMS |
| `res.design_cond` | < 1e6 | 设计矩阵条件数 |

**参数合理范围（1550 nm 归一化幅度单位）**

- |ε| = |B/A − 1| < 20%
- |δ| < 15°
- A、B > 0

---

### 2.5 NVRAM 存储格式（JSON 示例）

```json
{
  "version": 1,
  "lambda_nm": 1550,
  "cal_method": "factory_drift",
  "cal_date": "2026-08-24",
  "A": 1.023,
  "B": 0.912,
  "delta_rad": 0.0785,
  "epsilon": -0.108,
  "fit_arc_rad": 2.34,
  "fit_rms": 0.018
}
```

运行时加载 A、B、δ；**p、q 不写入文件**，上电后用在线算法初始化。

## 3. 在线运行（日常测量，跨表面/距离）

### 3.1 处理顺序（必须遵守）

```
原始 u,v
  → heydemann_apply（g,δ 用 NVRAM；p,q 用在线值）
  → z_c = I_c + j·Q_c
  → [可选] SLOW 档跟踪滤波（弱光/掉光门控）
  → 差分鉴相 Δφ = angle(z[n]·conj(z[n-1]))
  → x = (λ/4π)·unwrap(φ)
```

**椭圆校正必须在跟踪滤波之前**：未校正时 |z|² 带 2φ 纹波，会污染功率门控。

### 3.2 在线偏置跟踪（p、q）

换黑色表面、改距离后，**只更新 p、q**，A、B、δ 冻结。

**算法（每 50–100 ms 一块）**

```
p ← α·p + (1-α)·mean(u_block)
q ← α·q + (1-α)·mean(v_block)
α = exp(-Δt/τ)，τ = 50 ms（快跟）
```

**ρ 跳变检测（工况切换）**

```
ρ_med = median(|z_c - center|)
若 |ρ_med/ρ_ref - 1| > 20%：
  清空块缓冲；τ 临时缩至 20 ms 快速重捕 p,q；g,δ 保持冻结
```

### 3.3 状态机简表

| 状态 | 条件 | 动作 |
|------|------|------|
| S0 未标定 | 无 NVRAM | 默认 g=1,δ=0；尽快做台架标定 |
| S1 正常 | 有 NVRAM | g,δ 冻结；p,q 块均值 IIR |
| S3 重捕 | ρ 跳变 >20% | 仅加速 p,q；禁止用短弧更新 g,δ |

---

## 4. heydemann_apply 公式（实时，每样本 4 次乘加）

```
I_c = (u - p) / A
Q_c = ((v - q) / B - I_c·sin δ) / cos δ
z_c = I_c + j·Q_c
```

---

## 5. 验证标定是否成功

### 5.1 圆度（在线监测）

```
e_ρ = std(|z_c|) / mean(|z_c|)
合格：e_ρ < 3%（稳态）；> 8% 报警，检查 p,q 或复核 g,δ
```

### 5.2 小位移幅值（台架验收）

- 激励：100 nm @ 100 Hz，稳态 2 s。
- 锁相幅值误差：|â/a_true − 1| < **3%**。
- 本包仿真（出厂 g,δ + 在线 p,q，无大振动）：幅值误差 **0.2–0.6%**，RMS **~200 nm**。

### 5.3 2f 杂散（椭圆残差指纹）

解调位移谱在 2f₀ 处杂散应比基波低 **> 30 dB**；若只有 10–15 dB，说明 g 或 δ 仍偏差 > 5%。

## 6. 推荐默认参数表

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 块长（100 Hz） | 100 ms | 平掉振动，留漂移 |
| 偏置 IIR τ | 50 ms | 日常；切换时 20 ms |
| ρ 跳变门限 | 20% | 表面/距离切换 |
| 幅度门控 | ±5% | 标定段块功率 |
| 弧长门限 | π/2 rad | 低于此禁止更新 g,δ |
| fit rms 门限 | 0.05 | 圆化残差 |
| 标定抽稀 | ≤ 8000 点 | Heydemann 拟合 |

## 7. 常见失败与处理

| 现象 | 原因 | 处理 |
|------|------|------|
| `res.ok = False`，弧 < π/2 | 漂移太慢或时间太短 | 延长静置；轻触底座加速温漂 |
| 拟合成功但幅值仍差 >10% | 标定段幅度变化大（环带） | 收紧幅度门控 ±3%；避开通风 |
| 换黑面后幅值跳变 | p,q 未重捕 | 检查 ρ 跳变检测；缩短 τ |
| 圆度 e_ρ 周期性起伏 | g,δ 过期或错误 | 回台架用方法 A/B 重标 |
| 弱光下幅值发散 | 非线性/饱和 | 降增益；勿在标定段饱和 |
| 全程小振动从未标定 g,δ | 不可辨识 | **必须**出厂标定或长时间漂移标定 |
