# 零差 IQ 椭圆标定操作指南（Heydemann 校正，硬件不可改）

适用系统:λ = 1550 nm 零差光 IQ 干涉测振,采样率 250 MS/s(标定/参数跟踪在降采样 2.5 MS/s 流上进行,校正逐样本在全速率执行)。
适用场景:**硬件不可改**(全部为软件与操作流程方案);**现场可能长期无大振动**;**表面/距离频繁切换**(反光膜 → 黑面 → 远距等,回光幅度跳变可达 50 倍)。

信号模型(全文符号统一):

```
u(t) = A·cos φ(t) + p          I 路 ADC 输出
v(t) = B·sin(φ(t) + δ) + q     Q 路 ADC 输出
φ = 4π·x/λ + ψ(工作点漂移),  x 为目标位移
A = G_I·R,  B = G_Q·R          R 为回光幅度(随表面/距离变)
g ≡ B/A = G_Q/G_I              增益不平衡比(硬件常数)
ε ≡ g − 1                       增益不平衡(本系统台架实测量级 −10%)
δ                               正交相位误差(量级 4~5°)
p, q                            I/Q 偏置(电偏置 + 杂散反射,随工况/温度漂移)
```

对应代码:`ellipse_correction.py`(`heydemann_fit` / `heydemann_apply` / `fit_arc_gated` / `segmented_heydemann`);验证数据:`results_ellipse.txt`、`validate_ellipse_no_large_vib.py`、`validate_ellipse_switching.py`。

## 1. 标定什么、标定几次

| 参数 | 物理来源 | 随工况(表面/距离)变吗 | 标定时机 | 存放 |
|---|---|---|---|---|
| g = B/A(等价 ε)、δ | 光学 90° 混频器相位、两路探测器/放大器增益 | **不变**(硬件常数,只有 <0.1%/K 量级温漂) | **出厂/台架一次** | NVRAM(带 CRC) |
| A、B 绝对值 | G_I,G_Q × 回光幅度 R | 变(随 R 跳变) | **不标**。鉴相 `angle(z)` 只用比值 g;\|z\| 只用于门控和 ρ 跳变检测 | NVRAM 存标定时参考值 A₀,B₀ 仅作诊断 |
| p、q | 电偏置 + 杂散反射 + 温漂 | 变(每次切换表面/距离都可能跳) | **弧门控在线更新**(角扩展足够才拟合圆心;禁止块均值 IIR) | RAM(掉电丢弃,上电用 NVRAM 中 p₀,q₀ 起步) |

**每台设备的标定总次数:g、δ 一次(出厂),此后现场零次。** 现场只有 p、q 的自动在线跟踪,无需人工操作。

### 与大振动无关的说明

1. g、δ 由分束比、混频器相位、探测器增益决定,**与目标振动状态无物理关系**。大振动的唯一作用是"免费"提供覆盖整圈的相位弧,让椭圆一次拟合可辨识——它是标定的**机会**,不是**条件**。
2. 出厂标定用方法 A(激光调频)或方法 B(自然漂移)获得同样的弧覆盖,**不需要任何振动**。
3. 无大振动场景 30 s 仿真实测(`validate_ellipse_no_large_vib.py`,全程仅 50–80 nm @100 Hz 小振 + 慢漂移,含两次表面切换;审查修复后重跑):
   - **出厂冻结 p,q**(前 5 s 拟合后全程冻结):平均 RMS ≈ 1712 nm,相对 B1(≈69214 nm)约 **40×**;反光段幅值误差 ≈ 0.2%。
   - **弧门控在线 p,q**(`OnlineBiasTracker`,回光缩放圆心):平均 RMS ≈ 208 nm,三段幅值误差 0.2%/0.5%/0.3%。
   - 旧版曾报"330×"是仿真 bug(α 按样本算 + 出厂写死真值),**不可单独作为方案证据**。
   结论:**无大振动时 g,δ 只能靠出厂标定;现场 p,q 用弧门控更新(禁止块均值 IIR)。**

## 2. 出厂/台架标定 g、δ(三种方法按优先级)

三种方法共用同一拟合器 `heydemann_fit(u, v)`(Halir–Flusser 约束直接最小二乘,强制 4ac−b² > 0,含预条件化),返回参数 `p,q,A,B,delta` 与诊断量:

- `arc`:98% 稳健角覆盖弧(rad),抗离群点;`arc_all` 为全样本覆盖弧。
- `rms`:圆化后半径残差 `sqrt(mean((|z_c|−1)²))`,好拟合时 ≈ 单点相对噪声水平。
- `design_cond`:设计矩阵条件数。**注意它与噪声成反比**(台架实测:原始点噪声 0.5%/2%/5% 对应满圆 cond ≈ 200/50/20;干净块均值点可达 3×10²–3×10⁴),只作病态告警(>1e5 警告,>1e6 拒绝),不作主判据。

拟合内建拒绝:弧 < π/2、设计矩阵秩亏、二次型非正定时返回 `ok=False`,调用方必须冻结上一组参数。

### 2.1 方法 A:激光调频扫条纹(首选,若激光可调频)

原理:φ = 4πνL/c(L 为光程差/工作距离),扫激光频率 ν 即扫相位。扫 2π 所需频移 **Δν_2π = c/(2L)**:

| 工作距离 L | Δν_2π | DFB 电流调谐(典型 0.5–1 GHz/mA)所需电流 |
|---|---|---|
| 0.3 m | 500 MHz | ≈ 0.5–1 mA |
| 0.5 m | 300 MHz | ≈ 0.3–0.6 mA |
| 1.0 m | 150 MHz | ≈ 0.15–0.3 mA |

**前置条件**

- 激光频率可调(电流/温度/压电任一),调谐量 ≥ 3·Δν_2π。DFB 通常可以(电流调谐 0.5–1 GHz/mA);HeNe 通常不行,改用方法 B。
- 目标刚性夹持在台架上,已知 L;回光良好(建议校正后圆度噪声底 ≤ 2%,约 CNR ≥ 34 dB)。
- u,v 采集必须**直流耦合**(AC 耦合会吃掉 p,q 并扭曲椭圆,禁止)。
- 温度稳定 ±0.5 K,预热 ≥ 30 min。

**操作步骤**

1. 设定处理流采样率 2.5 MS/s(全速率 /100 抽取)。
2. 施加三角波扫频:峰峰 Δν ≥ 3·Δν_2π(≥3 条整纹),扫频率 f_sw = 50 Hz。此时条纹率 ≈ 2×3×50 = 300 条纹/s,每条纹 ≈ 8300 个样本,采样充分。(慢扫 1–5 Hz 也可,相应把记录时长延长到 10–30 s。)
3. 连续记录 u,v 共 2 s(N = 5×10⁶ 样本),存 CSV(两列 u,v)或 NPZ。
4. 运行标定工具(内部均匀抽取 ≤ 8000 点调 `heydemann_fit`):
   ```bash
   python3 calibrate_ellipse.py --csv sweep_iq.csv --mode direct --out ellipse_cal.json
   ```
5. 检查工具打印的诊断量是否全部满足下表"合格判据"。
6. 改变扫频起始相位重复步骤 3–5,共 3 次。
7. 一致性检查:3 次结果 max|Δg|/g < 0.5% 且 max|Δδ| < 0.2°,取 3 次中位数。
8. 按 2.4 节格式写入 NVRAM,并把 3 次原始诊断量存入出厂检验记录。

**合格判据(方法 A)**

| 项 | 门限 | 依据(台架蒙特卡洛,20 次中位数) |
|---|---|---|
| arc | ≥ 6.0 rad(满圆 98% 稳健弧理论值 6.16) | 满圆场景实测 6.12–6.13 |
| rms | ≤ 0.03,且 ≤ 2× 噪声底 | 噪声 0.5%/2%/5% 时 rms = 0.005/0.021/0.053 |
| design_cond | < 1e4 | 满圆实测 20–200 |
| 重复一致性 | \|Δg\|/g < 0.5%,\|Δδ\| < 0.2° | 2% 噪声下单次误差:g 0.05%、δ 0.03° |
| 参数合理范围 | \|ε\| = \|g−1\| < 20%,\|δ\| < 15°,A、B > 0 | 超出说明光路/接线异常,不是拟合问题 |

达成精度(2% 噪声、8000 点、满圆):**g 误差 ~0.05%,δ 误差 ~0.03°**——远优于在线任何方法,这是方法 A 排第一的原因。

### 2.2 方法 B:机械/温漂自然漂移扫弧(无调频能力时,静置 5–30 min)

原理:台架温漂/支架蠕变使工作点 ψ 缓慢漂移,块均值点 (ū_k, v̄_k) 沿椭圆缓慢画弧。块均值把单点噪声压缩 √N 倍(100 ms 块 = 2.5×10⁵ 样本,压缩 ~500 倍,块均值点残余噪声 ~0.005%–0.2%),因此**短弧也能高精度拟合**——这是方法 B 可行的关键。

小振动无害说明:若标定时目标有残余小振 a rad(峰),块均值半径统一缩为 J₀(a) 倍(例 a = 0.65 rad 时缩 10%),**等比例作用于 A、B,不偏移中心、不改变 g 与 δ**,无需剔除。

**前置条件**

- 目标刚性夹持,静置;确认存在自然漂移:观察 (u,v) 李萨如轨迹,10 min 内工作点移动 ≥ 1/8 条纹(漂移率 ≥ 0.02 条纹/s 时约 1–2 min 即可攒够弧)。
- 回光稳定(块均值半径波动 < ±2%,由幅度门保证)。

**操作步骤**

1. 处理流 2.5 MS/s,直流耦合记录 u,v;**块长 100 ms**,每块计算块均值点 (ū_k, v̄_k),入缓存(最多 200 点,先进先出)。
2. **幅度门**:以现有参数(初值 A=B=1, δ=0, p,q=首块均值)圆化后,剔除半径偏离缓存中位数 > ±2% 的块均值点(保留点不足 12 个时放宽到 ±4%);回光波动的环带点不得进入拟合。(离线工具 `calibrate_ellipse.py --mode drift` 用块功率中位数 ±5% 门,≈幅度 ±2.5%,等效。)
3. 用现有参数估算缓存点的角覆盖弧;**弧 ≥ 0.6π 才触发拟合**(π/2 是拟合器内建下限,贴着下限拟合会被边缘拒绝或给出大误差,见判据表)。
4. 触发后对缓存点调 `heydemann_fit`;`ok=True` 则记为一个"有效拟合",同时用新参数刷新幅度门与弧估计。离线等效命令:
   ```bash
   python3 calibrate_ellipse.py --csv drift_iq.csv --mode drift --fs 2.5e6 \
       --block-ms 100 --gate-frac 0.05 --out ellipse_cal.json
   ```
5. 继续静置,每 100 ms 重复 1–4。漂移每前进约 0.1π 就会产生新的有效拟合。
6. 收集 **≥ 10 个有效拟合**(典型 5–15 min;漂移 0.1 条纹/s 时约 5 min)。离线做法:把记录切成 ≥10 段分别跑工具。
7. 一致性检查:10 组结果 g 的标准差 < 1%、δ 的标准差 < 0.5°;取各参数中位数。
8. 若 30 min 仍无有效拟合 → 漂移不足,人为制造:吹风/手压台架边缘造 1–2 条纹慢漂,或改用方法 A;**不要**用敲击振动凑弧(冲击带来的幅度波动会污染拟合)。
9. 按 2.4 节格式写入 NVRAM。

漂移较快(≥ 0.5 条纹/s)的变体:直接用原始样本分段拟合(`segmented_heydemann`,段长 0.5 s、抽样 ≤8000 点、幅度门 ±2%、弧 < π/2 冻结)。慢漂 1.5 条纹/s 场景实测(`results_ellipse.txt` B3):各段弧 3.5–5.7 rad,ε̂ 误差 0.3–0.5%、δ̂ 误差 0.3–0.7°。

**合格判据(方法 B,块均值点拟合)**

| 项 | 门限 | 依据(块均值点 200 个、噪声 0.05–0.2%,30 次中位数) |
|---|---|---|
| arc(单次拟合) | ≥ 0.6π,推荐 ≥ π | 弧=0.7π:g 误差 0.08–0.6%、δ 误差 0.06–0.4°;弧=π:g 0.03–0.19%、δ 0.01–0.04°;**弧刚到 π/2:δ 误差可达 5°且常被内建门拒绝——不可用** |
| rms(块均值点) | ≤ 0.005 | 实测 0.0005–0.0024 |
| design_cond | < 1e5(块均值点干净,数值天然偏大) | 实测 3×10²–3×10⁴(噪声越低数值越大) |
| 有效拟合数 | ≥ 10 | — |
| 一致性 | std(g) < 1%,std(δ) < 0.5° | — |

达成精度(弧 ≥ π 聚合后):**g 误差 < 0.3%,δ 误差 < 0.1°**,满足小位移幅值 3% 预算(见第 4 章换算)。

### 2.3 方法 C:利用现场大振动(机会标定,非必须)

仅当现场恰好出现大振动(位移幅值 ≥ λ/4 ≈ 390 nm,单块内相位摆幅 ≥ π)时,可顺带核对/更新 g,δ。**它不是流程的一部分——没有大振动,方法 A/B 的出厂参数已经够用**(第 1 章 B8 数据)。

**前置条件**:已有出厂参数在用;某 100 ms 块内检测到相位摆幅 ≥ π(等价条件:块内 `angle(z_c)` 覆盖弧 > π)。

**操作步骤**

1. 在线状态机 S2 中开启机会拟合开关(默认关,见 3.6 节)。
2. 对该块原始样本(抽样 ≤8000 点)调 `fit_arc_gated(u, v, 当前参数, gate_tol=0.08)`(幅度门放宽到 ±8%,大振动下回光调制更深)。
3. 仅当 `ok=True` **且 arc > π** 才接受候选参数。
4. 与 NVRAM 出厂值比较:|Δg|/g < 2% 且 |Δδ| < 1° → 允许覆盖运行参数(NVRAM 不改,只改 RAM);超出 → **不覆盖**,记"椭圆参数漂移告警"(提示光路可能被动过或温度超范围,安排台架复标)。
5. 每次接受后记录 (时间戳, g, δ, arc, rms) 入日志,供趋势分析。

**合格判据(方法 C)**:arc > π;rms ≤ 0.03(原始点);与出厂值偏差 |Δg|/g < 2%、|Δδ| < 1°。

### 2.4 参数存入格式(NVRAM)

JSON 格式(`calibrate_ellipse.py` 的输出即此格式,方法 A 为 `cal_method="direct"`,方法 B 为 `"drift_block_mean"`):

```json
{
  "version": 1,
  "lambda_nm": 1550.0,
  "cal_method": "direct",
  "cal_date": "2026-08-24",
  "A": 0.512034,
  "B": 0.460831,
  "delta_rad": 0.078540,
  "epsilon": -0.1000,
  "fit_arc_rad": 6.13,
  "fit_rms": 0.0212
}
```

出厂检验记录在此基础上另存:`design_cond`、`n_pts`、3 次重复的 `g_spread`/`delta_spread_deg`、环境温度、以及上电起步偏置 `p0,q0`(注意 **p,q 不属于标定参数**,写入仅作上电初值,在线跟踪会立即覆盖)。

等价定长结构(嵌入式,64 字节,小端,CRC32 覆盖前 60 字节):

```c
struct EllipseCal {          /* offset */
    uint32_t magic;          /*  0: 0x454C4C50 "ELLP" */
    uint16_t version;        /*  4 */
    uint16_t method;         /*  6: 0=A,1=B,2=C */
    uint32_t utc_unix;       /*  8 */
    float    g;              /* 12: B/A */
    float    delta_rad;      /* 16 */
    float    A0, B0;         /* 20,24: 标定参考幅度,仅诊断 */
    float    p0, q0;         /* 28,32: 上电起步偏置 */
    float    arc_rad;        /* 36 */
    float    rms;            /* 40 */
    float    design_cond;    /* 44 */
    float    temp_C;         /* 48 */
    uint32_t n_pts;          /* 52 */
    uint32_t reserved;       /* 56 */
    uint32_t crc32;          /* 60 */
};
```

运行时归一化约定:装载后令 A := 1、B := g(绝对幅度对鉴相无用),`heydemann_apply` 只消耗 (p, q, 1, g, δ)。

## 3. 在线运行(无重标定)

### 3.1 数据流与处理顺序

```
u,v (250 MS/s 全速率)
   │
   ▼
heydemann_apply(p,q 在线值; A=1, B=g, δ 出厂值)     ← 逐样本,全速率
   │  z_c = Ic + j·Qc
   ▼
SLOW 跟踪滤波(PLL, fn=110 kHz, ζ=1.2, design_params.py)
   │
   ▼
φ̂ 累计鉴相 → x = λ·φ̂/(4π)

旁路(2.5 MS/s 降采样流): 块均值缓存 → **弧门控圆心拟合**更新 p,q / ρ 跳变检测 / (可选)机会 g,δ
```

**椭圆校正必须在跟踪滤波之前**,两个原因(实测见 `results_ellipse.txt` B4 行):

1. 未校正时 |z|² 带 2φ 纹波(幅度 ~ε 量级),会污染 PLL 的功率门控判决(SnrOn/SnrOff);
2. 跟踪滤波是相位域线性环,**修不了椭圆畸变**——B4(校正+SLOW)与 B3(仅校正)指标完全同级,滤波只在掉光/门控上有价值。

### 3.2 状态机 S0–S3

```
        ┌────────────────────────────────────────────┐
        │                                            │
 上电 → S0 初始化 → S1 捕获 ──3块完成──→ S2 跟踪 ──ρ跳变──→ S3 重捕
        (读NVRAM)   (p,q直通)     ▲       (p,q快跟)              │
                                  └────────3块直通完成───────────┘
```

| 状态 | 动作 | 退出条件 |
|---|---|---|
| **S0 初始化** | 读 NVRAM,校验 CRC。成功:A=1, B=g, δ=δ_NV, p=p₀, q=q₀。失败:g=1, δ=0(降级运行)+ 持续告警 | 立即 → S1 |
| **S1 捕获** | 连续 3 个 100 ms 块,p,q **冻结出厂值**(不做块均值 IIR);第 3 块后置 ρ_ref := ρ_med | 3 块完成 → S2;若 ρ_med < ρ_min(掉光)则停留 |
| **S2 跟踪** | 每块:① 全速率输出 z_c;② 更新 ρ_med、ρ_ref;③ p,q 弧门控更新(3.3 节);④ 监测 ρ 跳变(3.4 节);⑤(可选)机会 g,δ(3.6 节) | \|ρ_med/ρ_ref − 1\| > 0.20 → S3;ρ_med < ρ_min → 冻结全部更新原地等待,恢复后 → S3 |
| **S3 重捕** | 清块均值缓存与 ρ_ref;冻结 p,q 弧门控更新;p,q 保持切换前最后可信值;**标记该时刻位移不连续**(相位累计器重置或打标) | 缓存角扩展 ≥ ARC_MIN 且圆心收敛 → S2 |

g、δ 在全部状态中**冻结不动**(除非 3.6 节机会更新且通过 2.3 节判据)。

工况切换实测(`validate_ellipse_switching.py`,反光膜大振 → 黑面小振 → 远距小振,回光 1 → 0.05 → 0.02):带 S3 重捕的完整方案(B4)在切换后 B/C 段位移 RMS 比滑动去均值(B1)低 **47.9 倍**(3.7 µm vs 179 µm)。极弱回光段(回光 2%、SNR 5 dB)幅值误差仍受限于 CNR,这是物理极限,不是标定失败。

### 3.3 p、q 在线更新(弧门控圆心,禁止块均值 IIR)

**核心原则:g、δ 出厂冻结;p、q 只能在角扩展足够时更新,绝不能用块均值 IIR 直接跟 ū_k、v̄_k。**

原因(审查项 #1):固定工作点小位移时 `mean(u) ≈ p + A·cos ψ`,不是 `p`。对块均值做 IIR 会逐步把干涉矢量分量当偏置减掉,破坏校正。旧版 `validate_ellipse_no_large_vib.py` 因 α 按样本而非按块(≈1)使 p,q 冻结在真值,才误报 330× 改善。

**推荐实现(`OnlineBiasTracker`,块长 100 ms)**

```
块长 T_blk = 100 ms
每块: 缓存 (ū_k, v̄_k)
       用当前 p,q + 出厂 g,δ 做 heydemann_apply
       若校正平面角扩展 arc ≥ ARC_MIN(π/2) 且缓存 ≥ 12 点:
           由块均值弧估计圆心, p ← 0.8·p + 0.2·ĉ_x,  q 同理
       否则: 冻结 p,q
S1/S3: 冻结 p,q,仅更新 ρ_ref
```

**ρ 跳变时**:清空块均值缓存,冻结 p,q,待新工况自然漂移攒够弧后再更新。

**可选细跟——LMS 半径均匀化**(全弧覆盖或小位移长期漂移时):在校正平面每块执行

```
ρ_i = |z_c,i|,  θ_i = angle(z_c,i),  ρ0 = median(ρ)
Δp = μ·mean((ρ_i − ρ0)·cos θ_i)·A,  Δq = μ·mean((ρ_i − ρ0)·sin θ_i)·B,  μ = 0.02
```

原理:中心偏差使 ρ(θ) 呈 1φ 纹波,相关检测给出无偏梯度;与弧门控圆心互补。

**无大振动现场**:p、q 应主要依赖出厂标定值;在线更新仅在有温漂/慢漂积累角度时微调。切换表面/距离后靠 ρ 跳变进 S3,**不要**指望块均值在 0.3 s 内收敛到新中心。

### 3.4 ρ 跳变检测(表面/距离切换)

```
每块:  ρ_med = median(|z_c块|)                    (中位数天然抑制散斑闪烁)
       跳变判决: |ρ_med/ρ_ref − 1| > 0.20  →  进入 S3
       基准更新: ρ_ref ← 0.9·ρ_ref + 0.1·max(ρ_med, 1e-9)   (时间常数 ≈ 1 s)
掉光:  ρ_med < ρ_min = 0.1·ρ_ref  →  冻结全部参数更新,输出置无效
```

设计依据:表面切换的 R 变化通常 ≥ 2 倍(反光膜 R=1 → 黑面 0.05 → 远距 0.02),远超 0.20 门限;散斑闪烁时间尺度 10–100 µs ≪ 块长 100 ms,被块中位数平滑。粗糙面误触发频繁时,改为**连续 2 块**超门限才进 S3,或把门限升到 0.35。

### 3.5 heydemann_apply 公式(逐样本,全速率)

```
Ic = (u − p) / A
Qc = ((v − q)/B − Ic·sin δ) / cos δ
z_c = Ic + j·Qc          →  鉴相 φ̂ = angle(z_c)
```

实现注记:预计算 k₁ = 1/A、k₂ = 1/(B·cosδ)、k₃ = tanδ,则 `Ic = k₁(u−p)`、`Qc = k₂(v−q) − k₃·Ic`,每样本 3 乘 3 加,FPGA/DSP 定点可流水实现。保护:装载参数时检查 A>0、B>0、|cosδ| ≥ 1e-6(δ → ±90° 表示硬件正交完全丢失,拒绝装载并告警)。

### 3.6 机会性 g、δ 更新(可选,默认关)

按 2.3 节方法 C 执行:S2 中检测到某块弧 > π 时以 `fit_arc_gated(gate_tol=0.08)` 拟合,通过 arc > π、rms ≤ 0.03、与出厂值偏差 |Δg|/g < 2%、|Δδ| < 1° 全部判据才覆盖 RAM 参数。任何一条不过,冻结现值。**该开关关闭时系统行为与本章其余部分完全一致,不依赖它。**

## 4. 验证标定是否成功

三项检查全过才算标定成功;第 1 项出厂与现场都做,第 2、3 项在台架做。

### 4.1 圆度残差 std(|z_c| − 1)

1. 采集一段相位覆盖 ≥ 1 条纹的数据(台架:扫频或等漂移;现场:等自然漂移攒够,用 3.3 节缓存的角扩展判断)。
2. 用当前参数做 `heydemann_apply`,计算 `std(|z_c| − 1)`(与 `heydemann_fit` 返回的 rms 同一定义)。
3. 判级:

| std(\|z_c\|−1) | 判定 | 动作 |
|---|---|---|
| ≤ 0.01 | 优 | — |
| ≤ 0.03 | 合格 | — |
| 0.03–0.05 | 边缘 | 检查回光/CNR;若 CNR 正常(残差应 ≈ 单点噪声水平)则参数可疑 |
| > 0.05 | 不合格 | 重标(第 2 章);先排查是否幅度门失效混入变幅环带 |

### 4.2 小位移幅值误差 < 3%

1. 台架安装 PZT/压电镜参考源,施加**幅值 a = 100 nm、频率 100 Hz** 正弦(参考幅值用电容测微计或干涉标准装置溯源,不确定度 ≤ 0.5%)。
2. 记录 ≥ 2 s,走完整链路(校正 + SLOW 跟踪滤波),对位移谱取 100 Hz 复幅值。
3. 判据:**|幅值误差| < 3%**。
4. 加严抽检:a = 10 nm 重复一次,判据同为 < 3%。

参考实测(`results_ellipse.txt`,校正后 B3):100 nm @100 Hz 误差 −0.39%,10 nm @100 Hz 误差 −2.07%,均达标;未校正(B0)时 10 nm 误差 −3.87%,超差。无大振动现场以出厂冻结 p,q 为主(见 `results_ellipse_no_large_vib.txt`):反光段幅值误差约 0.2%,弱回光段受 CNR 限制。

### 4.3 2f 杂散(残余椭圆的指纹)

残余误差 ε_r(增益)与 δ_r(正交)在鉴相输出留下确定性纹波:

```
dφ ≈ (ε_r/2)·sin 2φ + (δ_r/2)·cos 2φ
位移峰误差 = (λ/8π)·sqrt(ε_r² + δ_r²) = 61.7 nm × sqrt(ε_r² + δ_r²)
```

例:完全不校正(ε = 10%,δ = 4.5° = 0.0785 rad)→ 61.7 × 0.127 ≈ **7.8 nm** 峰误差;目标 sqrt(ε_r² + δ_r²) < 0.05 → 残余峰误差 < **3.1 nm**。

**测法 1(回归法,首选)**:取 4.1 节同一段数据,令 dρ = |z_c| − median(|z_c|),对 φ̂(t) 最小二乘回归 `dρ_i = a·sin 2φ̂_i + b·cos 2φ̂_i`。由 dρ ≈ −(ε_r/2)·cos 2φ + (δ_r/2)·sin 2φ 得 **δ̂_r = 2a、ε̂_r = −2b**;判据 sqrt(ε̂_r² + δ̂_r²) < 0.05。

**测法 2(谱法)**:台架制造恒定慢漂(条纹率 f_d,例 1–2 条纹/s),位移谱在 2f_d 处出现杂散线;判据:校正后 2f_d 谱线比校正前**下降 ≥ 20 dB**,或绝对幅值 < 3 nm。

旁证:校正正确同时消除 |z|² 的 2φ 纹波,下游 PLL 功率门控的 SnrOn/SnrOff 判决抖动应消失。

## 6. 常见失败与处理

| # | 现象 | 根因 | 处理 |
|---|---|---|---|
| 1 | 拟合返回 `coverage arc < pi/2 ... freeze` | 弧覆盖不足(漂移太慢/振动太小) | 正常保护,冻结上一组参数继续用;台架标定改方法 A 或延长静置(2.2 节步骤 8) |
| 2 | 弧显示够(arc ≥ π/2)但多次拟合 δ 相互差好几度 | 弧贴着 π/2 下限,δ 本质欠定;噪声还会虚增测得的弧 | 把触发弧提高到 ≥ 0.6π、合格弧 ≥ π;必须做 ≥10 次聚合 + 一致性检查(2.2 节) |
| 3 | rms 远大于噪声底(如 CNR 对应 2% 但 rms=0.07) | 变幅环带混入拟合(回光波动)或工况切换横跨拟合窗 | 检查幅度门是否 ±2% 生效;剔除跨 S3 事件的数据段重拟 |
| 4 | `rank-deficient design matrix` | 点全挤在一小段弧/一个点上 | 同 #1;若在方法 A 中出现,检查扫频是否真的加上了 |
| 5 | 装载参数被拒:`delta ~ +/-90 deg` | δ 接近 ±90°,正交完全丢失 | 硬件故障(混频器/光路),停止标定,返修;软件无法补救 |
| 6 | 首段拟合 g 偏大且 rms 高,后续段正常 | 自举首段无门拟合吃了变幅环带(环带偏差) | 已内建两轮门控重拟(`segmented_heydemann`);若仍偏,丢弃首段结果,用第 2 段起的参数 |
| 7 | 圆度残差合格,但切换表面后头 0.3–0.5 s 幅值误差大 | p,q 尚在 S3 重捕收敛中 | 正常;S3 已标记不连续段,该窗口数据不用于评估。要求更快就把 T_blk 降到 50 ms |
| 8 | ρ 跳变频繁误触发(未换表面) | 粗糙面散斑深衰落长于块长,或目标缓慢离焦 | 门限 0.20 → 0.35;或连续 2 块确认;检查聚焦 |
| 9 | 掉光恢复后位移曲线跳台阶 | 掉光期间相位累计中断,本质不可恢复 | 接受:S3 会打不连续标记;按段处理位移数据,不跨段积分 |
| 10 | 小位移幅值误差 5–150%,校正"没效果" | 误用滑动去均值当校正(只能去偏置,修不了 ε/δ,小位移+慢漂下窗均值≠中心) | 禁用滑动去均值;走本指南链路(实测 B1 在 100 nm@100 Hz 误差 +148.7%,B3 为 −0.39%) |
| 11 | NVRAM CRC 校验失败 | 存储损坏 | 降级 g=1, δ=0 运行 + 持续告警(此时 10 nm 级位移幅值误差可到 ~4%,见 B0 数据);尽快按第 2 章重标 |
| 12 | 机会标定结果与出厂值差 >2%/1° | 光路被调过、温度超范围、或该次大振动块混入切换 | 不覆盖(2.3 节判据本身会拦);连续多次告警则安排台架复标并检查温控 |
| 13 | 极弱回光段(R ≤ 2%,SNR ≤ 5 dB)幅值误差仍达数十 % | CNR 物理极限,非标定问题 | 无软件解;提高回光(清洁/调焦/贴反光膜)。判别方法:圆度残差与 CNR 换算一致即说明标定本身正常 |

**三条"不要做"**

1. 不要在现场为了标定去制造大振动——出厂 g,δ + 在线 p,q 已满足指标(第 1 章数据)。
2. 不要把跟踪滤波放在椭圆校正之前——滤波修不了椭圆,2φ 纹波还会污染其门控(3.1 节)。
3. 不要相信"弧刚过 π/2"的单次拟合结果——那只是可辨识下限,不是质量保证(第 2.2 节实验)。
