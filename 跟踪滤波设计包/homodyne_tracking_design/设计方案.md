# 零差光 IQ 跟踪滤波分档方案(λ=1550 nm, fs=250 MS/s, 最高 3 MHz)

> **审查项 #7 更新(2026-08):** 原 ζ=2.65 由 NCO 路径等纹波推导,但双路径架构下**全输出平坦度由公共 4 MHz FIR 窗决定**,与 |H_L| 无关(`validate_zeta_sweep.py` 实测 ζ∈{0.7…2.65} 幅值误差极差 <0.05 pp)。已改回 **ζ=1.2**(`design_params.ZETA`);MEDIUM 恢复 B_loop<B_win,FAST@3MHz SNR 增益 +2.2→+7.9 dB。本文正文(§0–§6)已按 ζ=1.2 全面修订,旧推导以对比形式保留在 §4;数据以 `design_params.py` / `results.txt` / `results_zeta_sweep.txt` 为准。

仿真验证:`python3 validate_tracking.py`(全部断言 PASS);`python3 validate_zeta_sweep.py`(ζ 扫描 PASS)。
参数源文件:`design_params.py`;PLL 内核与参考项目 `pll_carrier_regen.m` 逐样本一致(`core.py`)。

## 0. 结论速览

| 档位 | fn | ζ | B_loop(连续/离散) | f_3dB(离散) | 3 MHz 处 \|H_L\|(NCO 路径) | 弱光线性上限 @B=40 MHz | 实测全输出 SNR 增益 @CNR 3 dB(设计频点) |
|---|---|---|---|---|---|---|---|
| SLOW | 110 kHz | 1.2 | 0.487 / 0.489 MHz | 0.31 MHz | −21.1 dB | +16.1 dB | **+38.5 dB** @100 kHz |
| MEDIUM | 530 kHz | 1.2 | 2.345 / 2.389 MHz | 1.51 MHz | −7.8 dB | +9.3 dB | **+18.8 dB** @1 MHz |
| FAST | 1.60 MHz | 1.2 | 7.079 / 7.494 MHz | 4.75 MHz | −0.76 dB | +4.5 dB | **+7.9 dB** @3 MHz |

核心修订(**审查项 #7**):**ζ 从 2.65 改回 1.2,fn 不动**。ζ=2.65 原来由"NCO 路径等纹波 ±3%"推导,但本架构是双路径:最终测量输出 `y_full = e^{jφ}·e^{j·gs·angle(FIR(z·e^{-jφ}))}` 把未跟踪残差经公共 4 MHz 窗重新并入,**输出平坦度由窗决定,与 |H_L| 无关** —— ζ 扫描实测(`validate_zeta_sweep.py` Z3-1):ζ∈{0.7, 1.0, 1.2, 1.8, 2.65} 在全部 档×频率 组合上全输出幅值误差极差 <0.05 个百分点。ζ=2.65 因此只付出代价:B_loop = 8.62·fn(vs ζ=1.2 的 4.42·fn),损失 ~2.9 dB 门限扩展余量,且把 MEDIUM 的 B_loop(4.57 MHz)推到 B_win = 4 MHz 之上,破坏 click 清除条件。ζ=1.2 下 NCO 路径确有 +11.5% 峰化 / 档边缘 −10%,但 NCO 单独输出只承担掉光飞轮与选档守卫职能,对纹波不敏感。

测量带宽的准确表述:**4 MHz 是公共窗的 −6 dB 截止点**,平坦(幅值误差 <1%)测量带约 **DC–3.6 MHz**,任何档相同(`validate_zeta_sweep.py` Z0 实测:|H(3 MHz)|−1 = +0.07%,<1% 平坦区至 3.63 MHz,−3 dB 点 3.89 MHz)。

## 1. 三档参数推导

### 1.1 ζ 的选择(审查项 #7,实测驱动)

连续近似闭环幅频(x = f/fn):

```
|H_L(x)|² = (1 + 4ζ²x²) / ((1−x²)² + 4ζ²x²)
```

ζ 不再由 NCO 路径纹波推导(那不是输出指标),而由 ζ 扫描(`validate_zeta_sweep.py`,ζ∈{0.7, 1.0, 1.2, 1.8, 2.65} × 三档 × 100k/1M/3M,CNR=3 dB)按三条实测证据选取:

1. **全输出幅值误差与 ζ 无关**(极差 <0.05 pp)—— ζ 在输出端什么都买不到;
2. **SNR 增益单调偏好低 ζ**(B_loop = π·fn·(1+4ζ²)/(4ζ) 越小、环内 CNR 越高、click 清除越完整):FAST @3 MHz 增益 ζ=2.65→1.2 从 +2.2 提到 +7.9 dB;MEDIUM @100 kHz 在 ζ≤1.8(B_loop<B_win)恢复 +38.5 dB(ζ=2.65 时 +36.2 dB);
3. **掉光重捕与 ζ 基本无关**(Z2:重捕时间由门控 AcquireTime=4·TauF 主导,各 ζ 的相位收敛 settle 均 ~1 µs)。

**为什么取 1.2 而不再降(0.7/1.0)**:FAST 设计频点 3 MHz 只再多 ~1 dB(+8.9 vs +7.9 dB),但 FAST 低频落在 click 清除悬崖边(B_loop ≈ 1.3·B_win,16 种子 p10–p90 跨 [+19, +40] dB 的双峰分布,中值不可依赖),且欠阻尼(ζ=0.7 时 NCO 路径峰化 +28%)。ζ=1.2 离悬崖有余量、阻尼适中,是环带宽经济性与稳健性的平衡点。

### 1.2 fn 的推导

`fn = f_max / 1.875`(沿用;输出平坦度由窗决定后,fn 只决定守卫误差与 B_loop 尺度):

- SLOW(f_max=200 kHz): fn = 110 kHz
- MEDIUM(f_max=1 MHz): fn = 530 kHz
- FAST(f_max=3 MHz): fn = 1.60 MHz

环路增益(θ = 2π·fn/fs, Kp = 2ζθ, Ki = θ²,ζ=1.2):

| 档位 | Kp | Ki |
|---|---|---|
| SLOW | 6.635e-3 | 7.643e-6 |
| MEDIUM | 3.197e-2 | 1.774e-4 |
| FAST | 9.651e-2 | 1.617e-3 |

### 1.3 门控参数推导

门控是**掉落检测器**,不是 FM 门限检测器(SnrOn 若设 3.0,CNR 3 dB 的弱光永远进不了 LOCK):

- **SnrOn = 1.0 / SnrOff = 0.3**(全档相同):最弱规格光 CNR 3 dB → snr 估计≈2.0 > SnrOn,可靠进锁;掉落 10 dB 即触发 SnrOff,迟滞比 3.3 倍防抖。
- **TauP**(功率平滑):估计相对标准差 ≈ 1/√(2·B_frontend·TauP)。要求 σ_rel ≲ 15 %(B=40 MHz 时 TauP ≥ 0.6 µs)且检测延迟 ≪ 最短散斑衰落(~10 µs)。按档位动态取:SLOW 4 µs(σ_rel 6 %)、MEDIUM 2 µs(8 %)、FAST 1 µs(11 %)。
- **TauF**(粗频率 IIR):σ_f ≈ fs/(2π)·1/√(2·B_frontend·TauF),需 ≪ 捕获范围(~20·fn)。SLOW 8 µs(σ_f≈0.6 MHz < 2.2 MHz)、MEDIUM 2 µs、FAST 1 µs;AcquireTime = 4·TauF。
- rel_on/rel_off = 0.20/0.08,tauRef = 200 µs(相对衰落判据,防止死通道分权重)。

## 2. 每档预期指标

公式:B_loop = π·fn·(1+4ζ²)/(4ζ) = 4.42·fn(连续,ζ=1.2);f_3dB ≈ 2.81·fn(连续);a_design = πλfn²;线性上限 = 10·log10((B_frontend/2)/B_loop);σ_φ² = B_loop/(CNR_lin·B_frontend)。

| 指标 | SLOW | MEDIUM | FAST |
|---|---|---|---|
| B_loop 连续 / 离散积分 | 0.487 / 0.489 MHz | 2.345 / 2.389 MHz | 7.08 / 7.49 MHz |
| f_3dB(离散) | 0.31 MHz | 1.51 MHz | 4.75 MHz |
| a_design (e_ss=1 rad) | 5.89e4 m/s² | 1.37e6 m/s² | 1.25e7 m/s² |
| 3 MHz 处 \|H_L\|(NCO 路径;全输出由窗决定,三档 3 MHz 误差均 <0.1%) | −21.1 dB | −7.8 dB | −0.76 dB |
| 线性上限 @B=40 M | +16.1 dB | +9.3 dB | +4.5 dB |
| 线性上限 @B=20 M | +13.1 dB | +6.3 dB | +1.5 dB |
| 锁内 σ_φ @CNR 3 dB, B=40 M | 0.078 rad | 0.171 rad | 0.298 rad |
| 实测全输出 SNR 增益 @3 dB(12 种子中值,设计频点) | +38.5 dB @100k | +18.8 dB @1M | +7.9 dB @3M |

两点必须说清:

1. **实测增益远超"线性上限"不是矛盾**:10·log10((B/2)/B_loop) 是已锁定线性区的相位底噪改善;CNR 3 dB 时 OFF 鉴频器深在 FM 门限之下,click 噪声抬高底噪,环内/窗内 CNR 越过门限后 click 消失——门限扩展的非线性收益叠加在线性收益之上,SLOW 实测 +38.5 dB。click 清除发生在复域残差窗内,条件是 **B_loop < B_win**:ζ=1.2 下 SLOW/MEDIUM(0.49/2.34 MHz)满足;FAST(7.08 MHz)只部分清除,低频增益 ~+13 dB。
2. **FAST 档的诚实边界**:B_loop=7.1 MHz 仍是三档中最宽,线性上限 +4.5 dB;σ_φ=0.30 rad @CNR 3 dB 偏大,弱光下 FAST 建议 CNR ≥ 6 dB。**FAST 档推荐 B_frontend = 40 MHz**(20 MHz 时上限只剩 +1.5 dB);SLOW/MEDIUM 用 20 或 40 MHz 均可。

## 3. 档位切换规则(守卫先行,选最窄通过档)

**主判据是跟踪误差守卫,不是目标频段**——测量带宽由公共 4 MHz 残差窗决定,与档位无关,任何档都能测到 3 MHz(V1 实测三档 3 MHz 幅值误差均 <0.1%);档位只改变载波环动态。因此在**通过守卫的档位中选最窄档**(最低 B_loop = 最高弱光灵敏度),与 `design_params.select_band` 一致:

1. **跟踪误差守卫(主判据)**:正弦运动 v_peak @ f_target 的多普勒相位幅值 φ_amp = 2·v_peak/(λ·f_target),环路未跟踪相位 φ_err = |1−H_L(f_target)|·φ_amp;要求 **φ_err ≤ 1 rad**(鉴相器 ±π 回绕,留安全余量)。按 SLOW→MEDIUM→FAST 顺序取第一个通过的档,全不通过取 FAST。例(ζ=1.2 实算,V4):3 MHz/20 mm/s → **SLOW**(φ_err≈0.01 rad,高频小振幅守卫极易通过;V1 实测 3 MHz 下 SLOW 增益 +9.3 dB 还优于 FAST 的 +7.9 dB);100 kHz/1 m/s → SLOW 4.87 rad 超限,选 MEDIUM(0.43 rad);100 kHz/6 m/s → MEDIUM 2.59 rad 也超限,选 FAST(0.30 rad)。该守卫取代早期恒加速度守卫(对反向快于环路建立时间的正弦运动过于悲观)与早期"频段优先"规则(后者对 3 MHz/20 mm/s 错误地给出 FAST,审计已纠正)。
2. **v_peak 未知时的保守默认(审计修订)**:`select_band(f, None)` 不再退化为频段规则——频段规则会把 100 kHz、实际 30 m/s 的目标错停在 SLOW(幅值误差 ~−90%)。现按仪器最大速度 `APP_V_PEAK_MAX = 30 m/s` 保守评估守卫:`cfg_for_frequency(100e3)`(默认 v_peak)选 FAST 并上报 `overrange=True`(`validate_tracking` V5)。要用窄档必须显式给出真实 v_peak。
3. **迟滞(产品入口 `select_band_hysteresis` / `cfg_for_frequency`)**:同样守卫先行 —— 升档立即生效;降档每次更新只降一档,防 f_target/v_peak 抖动导致 SLOW↔FAST 跳变。频率-only 的 rise/fall 阈值已废除(与守卫先行矛盾);`cfg_for_frequency(3e6, v_peak=0.02)` 带迟滞与否均返回 SLOW。
4. **运行时自动回退**:非 LOCK 占比 > 1 % 或 near-π 事件率 > 10 /s → 升一档;长时间干净且下档通过守卫 → 允许降档(每次一档)。
5. **降级区上报(审计项 2,选项 A)**:用户全域内唯一超守卫组合是 66–100 kHz × 高速(30 m/s 时 FAST φ_err 最大 1.50 rad,仍 < π,atan2 鉴相器线性,`select_band` 回退 FAST 可跟踪)。`cfg_for_frequency` 的 PLL cfg 返回 `phi_err / guard_ok / overrange`(`design_params.guard_flags`),`overrange=True` 即该降级区,产品必须上报。保持 FAST fn=1.6 MHz:提高到 2.1–2.2 MHz 虽可过守卫、且案例 c 含噪误差略优,但在 3 MHz 规格点损失 2.7–3.3 dB 弱光 SNR(B_loop 7.1→9.3/9.7 MHz 进一步超出 B_win)——实测对比与决策依据见 `study_fast_fn_options.py` / `results_fast_fn_options.txt`;降级区含噪相位完整性统计(50 seeds,86 MHz 物理一致前端:突发2π跳变 p95=1 每 0.5 ms,但净条纹误差 p95=132 周/0.5 ms——降级区位移积分无效,幅值/速度指标仍有效)见 `validate_app_30ms_100khz.py` A8。

## 4. ζ=2.65(旧)与 ζ=1.2(现)对比(审查项 #7 重扫)

| 项 | ζ=2.65(旧) | ζ=1.2(现) | 说明 |
|---|---|---|---|
| B_loop | 8.62·fn | 4.42·fn | 门限扩展余量 +2.9 dB |
| MEDIUM click 清除(B_loop<B_win) | 4.57 MHz > 4 MHz,不满足 | 2.34 MHz < 4 MHz,满足 | MEDIUM @100 kHz 增益 +36.2 → +38.5 dB |
| FAST @3 MHz 全输出 SNR 增益 | +2.2 dB | **+7.9 dB** | V1 实测(12 种子中值) |

| NCO 路径带内纹波 | ±3% | +11.5 % / −10 % | 仅影响载波路径单独输出(掉光飞轮/守卫),对测量输出无影响 |
| 掉光重捕(-20 dB / 50 µs) | ~33/9/5 µs(三档) | 同 | 门控 AcquireTime 主导,ζ 无关(Z2) |

## 6. 验证记录(全部 PASS)

- `validate_residual_alignment.py`(审查项 #4,18/18):`core.residual_mode`(产品路径)与验证路径幅度误差差异 <1 pp。
